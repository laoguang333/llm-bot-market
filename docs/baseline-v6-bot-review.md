# v6 运行前策略审查（2026-10-19）

审查范围：当前源码中的 v5/v6 实际参赛策略和默认 Swift 挑战者。审查在本轮 80 局运行前完成；精确源码哈希和冻结二进制由验收计划记录。没有仅依据历史版本放行。

| 实现 | 核对的行为和信息来源 | 结论 |
|---|---|---|
| baseline.rs：noise、grid | 账户 RNG 只生成自身订单、锚点和参数；估值只使用规则和已收到的信息。没有反解世界 RNG。 | 可运行 |
| baseline.rs：value、momentum、news、hold | 使用账户收到的新闻、终值区间、历史成交、盘口及自身资金。news 读取的是合法投递的私有消息，不是未投递未来。 | 可运行 |
| strategic.rs：hunter、shark、tracker | 趋势/历史分位/成交异常信号，合法知识估计及闲置费抵扣；检查了 requote、credit_topup 共用执行路径。 | 可运行 |
| coral.rs | 历史分位与持仓组合溢价，只使用已收到的区间信息；当前 last_tick 修正与公开结算规则一致。 | 可运行 |
| swift.rs：五个参数档及挑战者 | 只读取匿名成交、聚合盘口、时钟及自己的账户；不读新闻、分红预测、终值提示、种子或其他账户。参数均为有限、明确的已有接口值。 | 可运行 |
| common.rs、lib.rs | Knowledge 仅累计已收到的消息；jittered 只将账户种子散列为自身参数。工厂没有额外信息注入。 | 可运行 |

对实际策略文件检查了外部文件、网络、进程、环境变量、unsafe、世界生成调用和种子用途，未发现读取外部答案或重建隐藏世界的路径。Start.seed 可推导世界种子是已接受的设计，不将其本身列作缺陷；本轮策略未利用这种关系预测隐藏信息。

默认 Swift 的信息隔离测试、总预算/可售股数、空盘口与过宽价差行为由现有测试覆盖。历史测试中的 Falcon 和 Astra 维持此前审查的实现；本轮 Astra 的差异只有公开期末边界由 ticks_total 改为 last_tick，不引入新信息来源。

执行层仍可能拒绝超过当时可用资金/持股或动作上限的请求，这些按现行规则处理并在结果中完整统计。审查不是收益保证，也不声称基准所有策略都具有相同的信息条件。
