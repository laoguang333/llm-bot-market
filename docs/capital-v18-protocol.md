# v18 资本分散实验：预先约定

2026-10-21，基于 `cdcf87c`。用户要求保留简单网格，避免它承担大部分账户亏损。此次不修改任何 bot 实现或参数，不读取旧 bot 策略源码。

## 干预

保留 v17 的人数抽样、账户顺序、信息权限、世界、撮合和费用。每个匿名 Grid 账户从 40,000 元、每股 120 股降到 20,000 元、每股 20 股。多出的现金和每只股票汇成开局池，按策略权重分配，再在该策略匿名背景账户中等分。命名账户和后来追加的挑战者不参与。

整数余数按策略名及账户顺序确定性分摊，逐分、逐股守恒。不读取世界、未来价格或赛后成绩，不在盘中补贴。实现只在人数抽样后、Start 与账本基数建立前执行。

比较两种事前固定配置：

- `balanced`：Coral、Value、Hunter、Momentum、Shark 各 20%。
- `quotes`：Coral 35%、Value 25%、Hunter 15%、Momentum 15%、Shark 10%。

旧 v17 为对照。Coral 只是分担者，不整体取代 Grid；既有普通挑战者资金不变。

## 运行与选择

开发种子 83001–83010，各版本每世界重复两次，共 60 局；固定 release 二进制、4 市场线程、Windows 半核预算，所有基准串行。按种子和重复轮换版本次序。

先检查资金、每股总量、原账户身份、消息权限、新闻、股息和终值一致，零 bot 错误、禁用、跳过，守恒审计通过。

核心目标：Grid 平均亏损占比降至 35% 以下；任一策略平均亏损占比不超过 35%；至少 80% 运行中最大单策略亏损占比不超过 60%；初始单策略资本份额不超过 35%。亏损占比分母为所有亏损账户的绝对亏损之和，盈利不抵扣。总亏损为零时记零。

质量保护：全项质量通过次数不低于同批 v17；平均双边盘口覆盖降低不超过 5 个百分点。另记录深度、点差、断流、收益、强平、坏账和墙钟。当前基准自身未稳定达到全项 80%，不放宽原质量阈值，也不以策略盈利替代市场质量。

满足条件时，优先选择全项质量通过率较高者，其次为最大群体亏损集中度较低者；完全相同时选择 `balanced`。若两种方案均失败，保留失败记录，调整前另行记录理由，不消耗留出种子。

选定后冻结配置，使用未参与选择的 84001–84020，每版本每世界两次，共 80 局，按相同指标验证。未通过核心目标或质量保护不升级默认。多线程执行不要求逐笔复现。

## 局限

本轮解决资本集中与亏损集中，不保证 Grid 单账户回报改善。资本从 Grid 转移后，收益排序和成交路径会变化。初始现金和股票守恒不能保证末期财富一致：持股分布、股息、费用、坏账和兑现都会受交易影响。
