# 内置策略对比

2026-10-17。每个场景在种子 1–20 的 20 个随机世界里各跑一局（3000 tick，10 只股票），每个策略 4 个账户（noise 8 个），初始每个账户现金 20,000、每只股票 20 股，合计约 38,000。表里是 20 局的平均值，金额单位为元（引擎内部是分）。

复现：

```sh
./target/release/llm-market series scenarios/tournament.toml --out runs/st --seeds 20
./target/release/llm-market series scenarios/arena.toml --out runs/sa --seeds 20
```

## 结论

1. **按价值调仓、在泡沫里分批卖出的策略最稳。** combo（fund 加上组合股息的边际价值）在有散户的场景里 20 局平均百分位 95.8 ± 2.0，最差一局也有 90；fund 86.6 ± 2.6。它们的仓位随"价格 / 持有到底的价值"缩放：便宜时加杠杆买，贵到 1.6 倍价值时清仓，卖单挂在盘口最优价而不是价值价，所以能把泡沫卖在泡沫价上。
2. **刷成交额抵扣闲置费是实打实的收益。** 闲置费每 50 tick 收权益的 0.2%，成交额的 1% 可以抵扣。harvester（在价差内做市，结算前不够就跨价差补量）付的闲置费只有其他策略的四分之一到三分之一；在没有散户的 arena 里它是第一名（84.9 ± 12.6）。
3. **同一 owner 的两个账户对倒可以合法刷抵扣。** washpair 两两配对，一个挂卖一个吃，闲置费比 fund 少约 35%。规则只禁止单个账户自成交，不禁止同一 owner 的账户互相成交。这是规则层面的漏洞，要不要堵需要你定（见下文）。
4. **追涨杀跌的方差极大，靠散户才能活。** rider（带杠杆跟趋势、超过 2 倍价值就跑）在有 hold/momentum 这些追高散户的世界里有时第一（最好 96.8），有时垫底（最差 22.3），平均 63.8 ± 21.2；在 arena 里每局都几乎亏光（4.3）。
5. **只吃信息差不够。** sniper（只在价格偏离价值 3% 以上时带杠杆吃单，主要靠私有新闻）在两个场景都在 50 左右：新闻带来的偏离不常见，其余时间持币付闲置费。
6. **对照组里被收割的是做市和追涨。** 基线 maker 成交额最大却亏损最多，推测是被知情单反复吃掉，momentum 在高位加杠杆买入，hold 一直满仓付闲置费、拿着按终局股息只值一小部分的股票。

## 策略说明

| 名字 | 做法 |
|---|---|
| fund | 价值 = 剩余局内股息 + 清算期股息（含已收到的新闻）。目标仓位 = 权益/股票数 × 权重，权重在价格等于价值时为 1，到 1.6 倍价值降为 0，便宜时最高 1.5 倍杠杆。买单不高于市场最优买价加一跳，卖单不低于市场最优卖价减一跳。偏离 5% 以上直接吃单。结算前跨价差补够抵扣额。 |
| combo | fund，价值里加上组合股息的边际值：买入能凑成一套时加上奖金 × 剩余派息次数，卖出会拆掉一套时同样计入。负奖金组合会被自动回避。 |
| vulture | fund 的参数版：只在价值 9 折挂深买单，接住砸盘和强平，按价值卖出，2 倍杠杆。 |
| sniper | 不挂单，只在盘口偏离价值 3% 以上时按偏离大小带杠杆（最高 3 倍）吃单；没机会时卖一点还借款；结算前补抵扣额。 |
| harvester | 在价差内一跳挂双边，价格高于价值 5% 时库存目标降为 0；结算前不够抵扣就跨价差补量。 |
| rider | 快慢均线趋势跟随，2 倍杠杆，价格超过 2 倍价值或趋势反转就卖，最后 300 tick 清仓。 |
| washpair | 按账户编号两两配对，每个闲置周期内 8 轮：一方在价差中间挂卖，另一方下一 tick 吃掉；同一只股票上买卖方向轮流，两边都不会单边漂移。 |

## 需要你决定的规则问题

- **同 owner 对倒刷抵扣**：要不要禁止？可选做法是同 owner 账户之间的成交不计入抵扣额，或者干脆禁止同 owner 互相成交（撮合时跳过）。前者更简单，也不影响盘口。
- **对照组造成的早期泡沫**：hold 和 maker 在前 500 tick 把价格推到价值的 2–3 倍，之后对照组现金耗尽、成交几乎停止。这让"在泡沫里卖"成了主要收益来源。如果想让博弈更多发生在全程，可以调对照组的现金或行为，或者减少对照组、增加博弈型 bot 的比例。
