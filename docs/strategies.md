# 内置策略对比

2026-10-17（加入新闻区间之后重跑）。每个场景在种子 1–20 的 20 个随机世界里各跑一局（3000 tick，10 只股票），每个策略 4 个账户（noise 8 个），每个账户是独立的 owner。初始每个账户现金 20,000、每只股票 20 股，合计约 38,000。表里是 20 局的平均值，金额单位为元（引擎内部是分）。

新闻私下披露时只给每个知情账户一个包含真值的区间（宽度为变动标准差的 3 倍，第二阶段 1.5 倍），公开时才给精确值。fund 和 sniper 买入按区间下限估值、卖出按上限估值。

同一个 bot 的几个副本参数相同，会在同一时刻一起行动。momentum 和 rider 的趋势参数按账户随机放缩 ±30%（场景里显式给出的参数不放缩），避免几个副本同时砸盘。

复现：

```sh
./target/release/llm-market series scenarios/tournament.toml --out runs/st --seeds 20
./target/release/llm-market series scenarios/arena.toml --out runs/sa --seeds 20
```

## 结论

1. **按价值调仓、在泡沫里分批卖出的策略最稳。** 在有对照组的场景里，combo 平均 94.6 ± 5.0，fund 83.3 ± 3.9。它们的仓位随"价格 / 持有到底的价值"缩放：便宜时加杠杆买，贵到 1.6 倍价值时清仓。卖单挂在盘口最优价，而不是价值价。combo 再加上组合股息的边际价值，所以凑套的股票会多拿。
2. **刷成交额抵扣闲置费是实打实的收益。** 闲置费每 50 tick 收权益的 0.2%，成交额的 1% 可以抵扣。harvester 在价差内做市，结算前不够就跨价差补量，付的闲置费只有其他策略的三分之一左右。在只有博弈型 bot 的 arena 里它是第一（90.0 ± 8.4）。
3. **追涨已经没人接盘。** 对照组改得理性之后，没有人再高位接盘，rider 两个场景都垫底（7.7 和 4.8）。
4. **只吃信息差不够。** sniper 只在偏离价值 3% 以上时吃单。这种偏离不常见，其余时间它都在持币付闲置费，所以两个场景都在 52 左右。
5. **大跌的来源。** 大幅下挫主要有两种：一是趋势策略在趋势反转时一起用 IOC 卖单往下扫；二是大额减息新闻公开。盘口上稳定的买单基本都挂在价值附近（fund、vulture、value），所以价格一旦被砸，就会直接落到价值附近，中间没有承接。
6. **新闻区间对排名影响很小。** 加区间前后各策略的平均百分位变化都在 3 个点以内。原因是区间只影响新闻从私下披露到公开的那一段（每条约 60 tick）；其余时间价值仍然是"当前股息 × 剩余派息次数"，完全可以精确计算。harvester 的优势主要来自刷抵扣，而不是用价值做市。

## 策略说明

| 名字 | 做法 |
|---|---|
| fund | 价值 = 剩余局内股息 + 清算期股息（含已收到的新闻）。目标仓位 = 权益 / 股票数 × 权重：价格等于价值时权重为 1，到 1.6 倍价值降为 0，便宜时最高 1.5 倍杠杆。买单不高于市场最优买价加一跳，卖单不低于市场最优卖价减一跳。偏离 5% 以上直接吃单。结算前跨价差补够抵扣额。 |
| combo | fund，价值里加上组合股息的边际值：买入能凑成一套时加上奖金 × 剩余派息次数，卖出会拆掉一套时同样计入。负奖金组合会被自动回避。 |
| vulture | fund 的参数版：只在价值 9 折挂深买单，接住砸盘和强平，按价值卖出，2 倍杠杆。 |
| sniper | 不挂单，只在盘口偏离价值 3% 以上时按偏离大小带杠杆（最高 3 倍）吃单。没机会时卖一点还借款，结算前补抵扣额。 |
| harvester | 在价差内一跳挂双边，价格高于价值 5% 时库存目标降为 0。结算前不够抵扣就跨价差补量。 |
| rider | 快慢均线趋势跟随，2 倍杠杆。价格超过 2 倍价值或趋势反转就卖，最后 300 tick 清仓。 |

## 对照组

| 名字 | 做法 |
|---|---|
| noise | 在最新价 ±1% 内随机挂小单。 |
| maker | 围绕平滑后的成交价挂双边，按库存偏移报价。 |
| value | 在价值 ±3% 挂买卖单。 |
| momentum | 快慢均线趋势跟随，价格高于约 1.25 倍价值时不再买，高于约 1.6 倍价值时止盈。 |
| news | 收到私有新闻后顺着方向交易，新闻公开后平仓。 |
| hold | 每 50 tick 把现金买成价格不超过 1.15 倍价值的股票，长期持有拿股息；买价高于 1.5 倍价值时卖出四分之一。 |
