# v16 bot 生态调查（2026-10-21）

本轮使用主分支 `main` 的 `a2c7780`，默认基准为 v16。主分支已快进合并 Lattice 提交；仓库没有 `master` 分支。只阅读公共配置、注册表、规则、研究文档和赛后数据，没有查看旧 bot 的策略实现，也没有调整任何 bot、引擎或默认阵容。

## 口径

注册表共有 35 个策略名。当前基准有 17 种策略，其中 Swift 有两个资金和参数不同的账户，所以分别统计 18 个组；全市场人数在 103–227 之间。Almanac、Osprey 为额外研究候选，另外 16 个策略名主要用于历史场景或对照。

本轮在运行前固定 81001–81020 共 20 个种子。每个种子运行两次原样 v16，再分别追加一个普通 Almanac 或 Osprey，各运行一次，共 80 局；四臂顺序按种子轮换。release 构建、4 个市场线程，Windows 20 逻辑核心中共用 10 核亲和性预算，使用 arena gate 串行运行。正式协议、二进制和场景哈希、逐次命令与结果见 [结果 JSON](ecology-v16-results.json)。不根据本批成绩改参数。

原样基准成绩先在每局内对同类账户平均，再平均同种子的两次运行，最后对 20 个世界等权平均。重复运行不是额外独立世界。排名百分位越高越好；净收益为最终总权益／初始总权益减一，已含分红、期末兑现和实际费用。不是年化收益。

Almanac 和 Osprey 的成绩属于各自追加挑战者的市场，单列，不混进原样基准均值。两者均为现金 20,000 元、每股 20 股、普通消息倍率 1、无额外研究；追加账户会改变内生交易路径。固定世界下的新闻、最终股息、终值支付，以及原有账户初始配置逐组核对。

Horizon 有十倍本金和 1000-tick 远期研究；Titan 有十倍本金但普通消息；Grid 的现金和库存也更大。`swift-early-single` 的现金和初始股份只有标准账户的十分之一，且采用不同入场参数与单次入场规则。原样基准榜单衡量这些完整配置的实际表现，不能直接称作等资金、等信息的算法智力排名。

**Almanac：S，当前最有力的普通账户候选。** 同场胜 Horizon 19/20、Kestrel 19/20、Tide 20/20。公开消息的后续价格反应加日历仓位在当前环境十分有效；代价是对群体反应速度和世界生成规则较敏感。它进入基准、增加同类数量后还能保留多少优势，需要另测，本批不能保证。

## 对生态的判断

**当前是少数高效交易者、成熟流动性策略和大量弱资本共存的市场，尚不是整体均衡的强 bot 联赛。** 原样 v16 全场按初始资金加权的平均净收益只有 +19.69%，而头部策略可达数倍收益；高收益并非全市场普遍获得。

1. **Grid 是首要调查对象。** 它平均占全场初始权益 50.48%，成交额双边参与占比 19.69%，却亏掉约 97.64%。平均累计交易费、闲置费与利息约为初始权益的 13.3%，账面费用规模远小于总损失，不能简单归结为“手续费太高”。优先检查重新铺网格、库存方向、买卖参考价和末期持仓；本轮没有读实现或做消融，尚未给出具体根因。
2. **Coral 是真正重要的流动性骨干。** 初始资金占比只有 4.42%，成交额双边参与占比达 24.67%，同时保持正收益。它不是排名最高的策略，但对比赛的价值很大。成交参与占比不区分主动/被动成交，不能当作独立做市贡献测量。
3. **名称数量大于独立思路数量。** NewsV2 与 Swift 共享信号路线；Horizon 延续 Titan 的普通交易核心；Osprey 基于 Kestrel；Tracker 带 Shark 内核；三个 Astra 基于 Coral。Lattice 的每局在线拟合、Almanac 的消息反应曲线、Tide 的股息恢复，增加了方法差异，但仍会争抢相同信息与流动性。
4. **资源和容量必须单列。** Horizon 的高分有研究权限支持。小资金 Swift 本轮最大杠杆只有 1，但只有约 0.03% 的市场初始权益；其高收益率不等于能管理十倍资金。既有同类拥挤研究也说明，单个策略成功不保证大量复制后仍成功。
5. **成本与期限规则对策略选择影响很大。** 每 50 ticks 的 0.6% 闲置费、逐 tick 派息和期末兑现，会惩罚消极等待与错误的后期持仓。Lattice 的平均累计费用约为初始权益的 400.3%，Tide 为 110.8%；这是随权益增长累计的费用，不是单笔费率，也不是只改变费用就能得到的因果收益差。

Horizon、Tide、Kestrel、Lattice 与 Grid 的直接成交额占各自总成交额约 23.2%、25.9%、23.9%、31.6%。这些是接触程度，**不是利润来自 Grid 的比例**。股息、组合收益和坏账核销也与 treasury 发生现金流，不能把所有赢家的利润都解释成纯零和转移。

下一步更值得做的是 Grid 的报价/库存归因、标准与小资金 Swift 的同资金同参数对照，以及普通权限下头部策略的统一比赛。暂不建议只靠继续添加新名字提高基准难度；也不建议直接删除所有弱参与者，因为这会同时改变流动性、资金和供给。

## 运行质量与边界

80 局完成 1600 次守恒审计，全部账户零 bot 错误、零跳过、零禁用。原始报告哈希及所有基准组平均百分位另从原始账户记录独立核对。

| 市场 | 质量全项通过 | 失败检查及场数，可重叠 |
|---|---:|---|
| 原样 v16 | 27/40 | 双边盘口 13、最长无成交间隔 11、成交覆盖 3、偏离两倍参考价值 2、中位价值偏离 1 |
| v16＋Almanac | 12/20 | 双边盘口 8、偏离两倍参考价值 1 |
| v16＋Osprey | 12/20 | 双边盘口 7、最长无成交间隔 2、偏离两倍参考价值 1 |

原样基准没有达到市场质量 80% 的目标；挑战者分数通过与这一点不矛盾。不能仅凭 60% 对 67.5% 就认定某候选造成质量下降，本轮没有做同次数的性能或因果验收。

原样基准的 Grid、Shark、Tracker 出现盘中强平及坏账核销，三组被强平账户占组内人数的逐世界平均分别为 2.98%、1.44%、1.25%。这 40 局没有期末负权益。Grid 40 局合计约 191 万次拒单，说明执行层也值得调查；拒单不等于 bot 崩溃或守恒失败。

额外 Almanac 挑战的 seed 81013 则出现一个期末资不抵债账户 `tracker#0`：初始权益 77,282.60 元，最终现金 −484.09 元、持股兑现 292.38 元，最终权益 **−191.71 元**，净收益 **−100.25%**。该账户盘中强平和坏账核销均为零，最大标记杠杆为 3.00。这再次说明盘中杠杆检查与期末偿债能力不同；不能把“没有强平”当作没有尾部风险。本轮没有改动或掩盖该结算结果。

全部模拟墙钟合计 312.67 秒，含启动与报告写出的 CLI 墙钟合计 343.20 秒，单局模拟墙钟中位数 3.87 秒。平均单次调用耗时：Lattice 2.64 微秒、Kestrel 3.07、Tide 1.79、Horizon 12.61；这些平均数包括策略不交易或等待的调用，不是纯训练步骤耗时。

当前规则接受个人时钟与逐 tick 舍入带来的少量权益差异，见 [逐 tick 股息说明](per-tick-dividends.md)。本轮评价属于现有模拟规则，不将守恒通过扩大解释为所有收益归因已得到证明。

## 不在当前基准的历史实现

以下评价依据对应旧版本报告，不是本轮 v16 测试成绩。等级是研究判断：B 表示有合理机制、旧测试中有竞争力；C 表示能力有限或证据不稳定；D 表示已有明显失败证据。没有新数据的策略不硬塞进当前排行榜。

| 策略 | 历史证据与我的评价 |
|---|---|
| `news` | D：旧事件计划按尝试次数结束，存在退出和多股票处理缺陷；适合作为历史对照。 |
| `news_fixed` | C：修正事件生命周期后行为更完整，但旧 v6 平均百分位 52.23，修复正确性没有自动创造足够交易优势。 |
| `fund` | B：现金流估值、仓位控制与末期收敛是扎实基础。旧 tournament 百分位 73.6；当前强对手更多，需要重测。 |
| `combo` | B+：将配套持仓的边际股息纳入估值，有明确经济依据。旧 tournament 77.5，旧 v4 单账户挑战 71.1；组合价值不能替代行情和执行控制。 |
| `vulture` | B：折价接货、等待恐慌抛售的定位清楚；旧 tournament 70.4。流动性和终值风险是核心约束。 |
| `sniper` | B−：只吃明显错误报价，旧 tournament 73.8；机会稀疏，高闲置费市场不利于长期等待。 |

| `rider` | D：简单趋势加杠杆，旧 tournament 2.7、arena 5.4；曾明显被反转和拥挤拖累。 |
| `drift` | C+：惯性信号存在，但跨价差交易后收益很分散；旧 v3 两批留出 80.7、72.5，均未达门槛。 |
| `astra_a` | B−：共同新闻区间池化、库存和末期收敛；旧 v5 两批留出 88.10、81.66，泛化不足。 |
