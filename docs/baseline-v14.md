# v14：Tide 与 Kestrel 进入基准

归档说明：当前默认已升级为 [v15](baseline-v15.md)，以下记录 v14 晋级时的配置与实验。复跑 v14 请显式使用 `scenarios/baseline-v14.toml`。

默认 `scenarios/baseline.toml` 与 `scenarios/baseline-v14.toml` 完全相同。保留归档 v13；新基准在 v13 末尾各追加一个 Tide、Kestrel，原有策略分组、人数区间、资金、参数和权限逐项不变。

新增账户为 `tide-incumbent`、`kestrel-incumbent`，各现金 2,000,000 分（20,000 元）、每只股票 20 股，新闻倍率 1，无额外研究，策略使用默认参数。总体为 **102–226 个账户、16 种策略**。新增合计现金 40,000 元、每只股票 40 股，因此不是固定总资金的替换实验。

Tide 按低股息的预期恢复估值、分散持仓并补成交额抵扣闲置费；Kestrel 按收到的新闻估值、市场比值、成交方向和动量调整仓位。两者竞争原有流动性及持仓机会，可能改变价格、成交与其他账户收益；加入后不保证保留单独挑战时的收益。没有修改决策频率、撮合、消息投递、结算或引擎规则。

## 晋级核验

2026-10-20，使用上一轮已审查并通过 8 项策略 release 测试的源码与程序；本次不修改策略实现。`tools/validate_v14.py` 逐项核验配置差异、实际账户名、人数、初始资金与股份，以及新增账户无额外研究权限。源码、程序和场景哈希保存在 `runs/v14-validation/manifest.json`。

Windows 共用半机 10 核预算，4 个市场工作线程，release 程序串行运行。种子 7、27006、28012，各版本每种子重复 2 次，交替顺序，共 12 场。240 次守恒审计通过，所有账户 0 bot 错误、0 禁用、0 跳过决策；6 对比赛的新闻、最终股息、期末兑现抽签一致。相同种子原成员人数不变，总人数恰好增加 2。

| 场景 | 三个种子账户数 | 单场模拟实际耗时中位数 | 市场质量全部通过 |
|---|---|---:|---:|
| v13 | 160 / 175 / 183 | 4.861 秒 | 2/6 |
| v14 | 162 / 177 / 185 | 4.936 秒 | 3/6 |

耗时中位数约增加 1.54%；样本很小且没有预热，这只是晋级回归记录，不是严格性能结论。质量检查并非全部通过，没有放宽规则。这是三个独立世界，重复不能算六个独立世界，也不是新的挑战者留出认证。详细结果见 [baseline-v14-results.json](baseline-v14-results.json)。

```sh
python tools/arena_gate.py --cwd . -- python tools/validate_v14.py
```

验证脚本拒绝覆盖既存输出；首次运行需 `runs/v14-validation` 不存在。正常使用可运行：

```sh
target/release/llm-market.exe run scenarios/baseline.toml --out runs/v14-example --seed 7 --threads 4
```

## 持续加入强策略的含义

历史配置的策略种类和人数范围如下，策略数量按不同工厂名计数，两个 Swift 算一种；这不是同一市场规则下的纯难度曲线。

| 版本 | 策略种类 | 账户数范围 | 主要变化 |
|---|---:|---:|---|
| v1 | 6 | 25–58 | 初始群体 |
| v2 | 7 | 27–63 | Hunter |
| v3 | 8 | 29–68 | Shark |
| v4 | 9 | 31–73 | Tracker |
| v5 | 10 | 33–78 | Coral |
| v6 当前归档 | 11 | 98–222 | Swift、群体扩容、NewsV2 替换旧 News |
| v7–v10 | 12 | 99–223 | Titan；期间还有时长及世界模型变化 |
| v11 | 13 | 100–224 | Horizon v2 |
| v12 | 13 | 100–224 | Horizon v3 替换 v2 |
| v13 | 14 | 100–224 | 部分 Noise 名额换成 ProfitEffect |
| v14 | 16 | 102–226 | Tide、Kestrel |

旧 bot 代码留在仓库不等于仍在默认阵容；例如旧 News 与 Horizon v2 已被替换，五个 Swift 曾缩为两个。Hunter、Shark、Tracker、Coral 等老成员确实仍在。

不断纳入曾经的成功策略，可以检验新策略在更丰富对手中的适应性。同类交易会竞争相同机会，可能压缩收益；但拥挤、同向减仓也可能创造新机会，强弱关系可能随阵容反转。因此“新版本更难”与“新 bot 比所有旧 bot 强”都需要实测，不能由晋级本身推出。

当前正式门槛是平均排名百分位 ≥90、至少 80% 世界进入前 25%。分母是所有账户，按初始权益归一化收益排名；打穿不要求第一名。若弱账户仍占多数，超过它们就能有高百分位，旧强者仍可排在新 bot 前面。这一门槛衡量对整个群体的竞争力，不能单独证明代际进步。

后续可保留当前全市场基准，并另设固定人口与资金的强策略对照组，分别报告全场百分位、对旧强者的胜率、净收益与尾部损失；本次未更改门槛或另设赛制。保留多样行为有助于模拟异质市场，淘汰所有弱策略会改变研究问题。
