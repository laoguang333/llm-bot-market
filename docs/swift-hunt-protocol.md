# Swift 单一狩猎者实验方案

本实验针对冻结的 Swift，背景市场为原版 v5。每局恰好一个 Swift，标准现金 20,000 元及每股 20 股；对手为单一账户，现金 200,000 元及每股 200 股。初始权益恰好十倍，杠杆、费用和信息规则没有特权。

## 信息约束

Falcon 只保留交易执行规则，从自己的公共盘口、匿名成交和中价序列重建 Swift 的信号。禁止使用 seed、账户序号、其他账户状态、新闻、股息或终值。知道参数不等于知道目标的内部状态或下一次动作。自己的历史成交可能包含在公共成交中。

收益和成交归因在比赛结束后由独立 Python 程序计算；分析器可以读取成交身份，但该资料从不输入 bot。

## 开发候选

每个候选均使用固定参数，先比较不同思路，不做参数网格。开发种子为 10001–10008；每组交换目标与对手在原阵容末尾的注册顺序，其他账户不变。

| 名称 | 行为假设 |
|---|---|
| pursuit | 同方向提前进场、提前退出，用大资金争抢最优档成交机会 |
| reverse | 在 Swift 卖出信号时买，在 Swift 买入信号时卖，测试反向承接 |
| supply | 提前持仓，在预测 Swift 买入时挂卖单供给，信号转弱提前撤退 |
| pressure | 在 supply 基础上增加中价下方 1% 的真实买单，影响 Swift 的盘口项；订单可被任何人实际成交 |
| cash | 卖出开局股票后持现金，测量少承担市场风险的相对优势 |
| blind | 取消方向判断、固定仓位暴露的对照 |
| coral | 十倍资金的默认 Coral，代表不专门针对 Swift 的成熟策略 |
| alone | 仅 Swift 加入原 v5，供参照；账户数不同，不单独用作因果结论 |

Falcon 通常目标总杠杆 1、单股目标比例 25%，早入阈值 0、早出阈值 −0.05；所有模式最后 40 tick 尝试退出。pressure 的买单需要真实购买力，卖单需要真实股票，不绕过撮合或账户约束。

## 选择与验收

开发先看对手相对 Swift 的收益率差、胜局比例，以及 Swift 相对于同资金对照的收益变化。均值优势需要连同中位数和双方绝对损益解读；若都失败，保留失败结论并记录进一步开发的理由。

选定实现后冻结源码、配置和二进制哈希，在全新种子 11001–11020 上同时测试候选、cash、blind、Coral 和 alone，再在 12001–12020 复核。每个双账户处理都交换注册顺序；两次顺序作为同一个种子的重复测量，置信区间按种子聚类抽样，不能把它们当成独立世界。

主要指标为每局对手收益率减 Swift 收益率，同时报告双方收益中位数、亏损局、双方都亏且对手亏得更少的局数、最大回撤、绝对损益和直接成交占比。对目标的压制量使用同种子同顺序对照，但价格会内生改变，不能当成固定价格重放。

稳定相对胜出要求两批均有正的平均收益率差、超过半数对局胜出，并检查合并的按种子聚类 95% 区间是否排除零。主动针对的额外效果另看相对于 cash、blind 和 Coral；不以目标亏钱本身认定狩猎者成功。

全体账户决策跳过、错误、停用、账务审计及策略拒单和强平一并公开。保持 Swift 和市场引擎不变。实验可能得出“没有找到有效狩猎者”，这不等于证明不存在狩猎策略。
