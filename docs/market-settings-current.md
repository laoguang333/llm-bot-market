# 当前 v18 市场设定与种子差异（2026-10-21）

默认 `baseline.toml` 与 `baseline-v18.toml` 相同：1 万 ticks，沿用 v15 的大龙成长分化起点约 1/3（tick 3333）。高点窗口仍在全局 87%–97%，回落窗口仍在 67%–81%；v15 从 55% 提前分化起点，主要延长成长时间，不是将整个路径平移。候选共同的早期成长在新起点前完成；远期研究的身份保护截止点同步调整，实际分红变化仍等待新闻生效。

v17 在 v16 阵容末尾加入普通 Almanac 与 Osprey v2 各一个，合计 105–229 个账户、19 种策略；保留 Tide 与 Kestrel 各一个普通账户、两个 Swift、NewsV2、普通权限十倍 Titan、Horizon v3 和 ProfitEffect 群体。Lattice、Almanac 与 Osprey v2 均为现金 20,000 元、每股 20 股、消息倍率 1，无额外研究。费用、撮合、原有 bot 决策频率和终值规则不变；Lattice 每 5 ticks 决策，新增交易者会改变竞争和成交路径。v18 保留该阵容，单独调整开局资本分布；正式场景与对照见 [v18](baseline-v18.md)，此前阵容见 [v17](baseline-v17.md)，成长时间见 [v15](baseline-v15.md)，原阵容见 [v14](baseline-v14.md)，终值缩放见 [v10](baseline-v10.md)，另见[远期策略与权限](horizon-bot.md)、[强平核对](liquidation-audit.md)。v17 及更早场景均保留。

另有 [v20 分红风险实验](dividend-v20.md)，显式开启 `world.dividend_risk` 后支持持久衰退和长期零分红。实验未替换默认，以下仍描述 v18；新字段缺省时历史世界保持原机制。

[v21](ecology-v21.md)进一步校准了中等分红风险，并实现 Harbor / Relay 对照场景和按分红状态分类的盘口诊断。新策略开发与独立生态验收均失败，未切换默认；固定组合与全部费用规则继续保持原样。

[v22](ecology-v22.md)使用独立实验场景研究较低收费、七类基础生态与有限风险约束，增加真实盘口、消息响应和持续生存的离线报告。它没有切换默认；以下 v18 费用、阵容和权限不变。实验中的零闲置费仍保留交易费及融资利息，不能理解为交易免费。

## 种子改变什么

另有可独立运行的 [v19 五类支付群体实验](payer-v19.md)，新增信息弱者、迟到者与有限库存网格。它尚未替换默认；下文的人口、资本和策略说明仍对应 v18。

| 项目 | 随种子改变吗 | 当前规则 |
|---|---|---|
| 股票、行业及敏感度 | 否 | 固定 10 股、3 行业，见下表 |
| 各股初始股息 | 否 | 固定初始值；后续才由新闻改变 |
| 未来新闻 | 是 | 发生时间、层级、方向、幅度、涉及的行业/股票 |
| 平静/动荡状态 | 是 | 切换时间、次数及持续长度 |
| 未来股息路径 | 是 | 普通三层新闻形成基础路径，所有股票另有阶段性强弱，叠加非负额外股息；都在新闻生效时改变派息率 |
| 大龙与候选 | 是 | 50% 世界有一个指定者；三个隐藏候选，前 1/3 的消息不透露谁会获得后续持续增长偏置，不保证每个指定者都长成 |
| 开局参考价格 | 是 | 初始普通股息对应的预计剩余现金流 × 0.85–1.15 |
| 组合配对、每套奖金、发放周期 | 否 | 固定五组，新闻不会修改组合规则 |
| 背景策略人数 | 是 | 各组分别在其范围中抽取；合计 105–229 人（含固定 Titan、Horizon、Tide、Kestrel、Lattice、Almanac、Osprey 各一个） |
| 每类账户的初始现金/股数 | 部分 | Grid 实际为 2 万元、每股 20 股；五类接收方额外分配随双方人数变化。相同世界总现金及每股总量与 v17 一致 |
| 谁先收到消息、收到什么区间 | 是 | 每事件、每账户分别生成；早期信息可能仍无法确定方向 |
| 背景 bot 的随机动作与部分参数 | 是 | 使用各账户种子；Coral 已启用参数扰动，显式固定参数优先 |
| 两个 Swift 的信号参数 | 否 | 标准版与 early-single 使用各自固定参数 |
| 期末兑现倍数与私人提示 | 是 | 全市场共用一个隐藏整数 N，当前范围 33–167，随对局时长缩放 |
| 费用、杠杆、撮合规则 | 否 | 固定规则见后文 |
| 实际价格、成交、持仓和收益 | 是 | 由上述世界条件和所有 bot 的交易共同形成 |

同一配置、种子的外生世界可以重建，但多线程成交顺序不要求确定性，因此同 seed 的普通运行、重新运行和录制模式也可能出现不同成交路径。

## 股票与初始股息

普通股息和新闻 delta 的内部单位是 **1/50 分/股/tick**，下表已换算成分。不是百分比收益率，也不是每 50 tick 的股息。

| 股票 | 行业 | 初始股息，分/股/tick | 全市场冲击敏感度 | 行业冲击敏感度 |
|---|---|---:|---:|---:|
| T1 | 科技 tech | 2.00 | 1.4 | 1.2 |
| T2 | 科技 tech | 1.60 | 1.3 | 1.0 |
| T3 | 科技 tech | 2.40 | 1.2 | 0.9 |
| T4 | 科技 tech | 1.20 | 1.5 | 1.1 |
| C1 | 消费 consumer | 2.00 | 0.8 | 1.0 |
| C2 | 消费 consumer | 1.80 | 0.7 | 1.1 |
| C3 | 消费 consumer | 2.20 | 0.9 | 0.9 |
| E1 | 能源 energy | 2.00 | 0.6 | 1.2 |
| E2 | 能源 energy | 2.60 | 0.5 | 1.0 |
| E3 | 能源 energy | 1.40 | 0.7 | 0.8 |

开局价格使用初始普通股息乘以 9999 次游戏内派息，加上期末 N 的公开范围中点 100 对应的 5000 ticks，再乘种子决定的 ±15% 因子，最后对齐到 1 分。这个开价公式不计组合奖励，也不偷看未来新闻或隐藏的真实 N。例：T1 中心开价为 `0.02 元 × (9999 + 100×50) = 299.98 元`。配置中另写的 `initial_price = 10000` 在开启 `opening_spread` 后不作为真实开价；初始订单簿为空，由 bot 建立报价。

## 全局状态与三层冲击

开局是平静状态。每 tick 从平静转为动荡的概率为 0.002，从动荡转回平静的概率为 0.01。若不考虑比赛截断，平均一段平静约 500 ticks、动荡约 100 ticks；不是固定每 500 tick 出事或每 100 tick 恢复。状态对 bot 公开，全市场共用一条状态路径，没有给三个行业另外生成各自的动荡状态。

每个 tick 分别抽取市场、各行业、各股票是否产生事件：

| 层级 | 平静期生成频率 | 动荡期生成频率 | 平静期冲击标准差 | 影响范围 |
|---|---:|---:|---:|---|
| 全市场 | 每 1000 tick 期望 1.5 次 | 4.5 次 | 8% | 全部 10 股 |
| 行业 | **每个行业**每 1000 tick 期望 2 次 | 6 次 | 10% | 该行业股票 |
| 个股 | **每只股票**每 1000 tick 期望 2 次 | 6 次 | 12% | 该股 |

实现是逐 tick 的概率抽签，并非预设固定冲击时刻。这些数值是生成概率对应的期望，不保证每段时间达到该次数；四舍五入后所有变化为零的候选会丢弃。三行业、十股票各自抽取，因而个股新闻总数通常最多。不同层级或不同行业的事件可以发生在同一 tick。

每个事件只抽一个均值为零的正态冲击 `x`。平静时标准差用上表，动荡时乘 2，即 16%/20%/24%。对于事件涉及的股票：

`变化量 ≈ round(max(D, 初始股息/2, 1) × 该层敏感度 × x)`

`D` 是按事件生成顺序累计到本事件之前的股息率；内部生成时已累计先前安排但可能尚未公开/生效的消息，不是强制让账户提前看到或领取这些股息。事件统一延后 120 ticks 生效，因此这一累计顺序也对应将来的生效顺序。

全市场事件在各股间共享同一个 x，用各股不同的市场敏感度缩放；行业事件在该行业股票间共享 x，用行业敏感度缩放；个股事件的敏感度为 1。现在所有敏感度均为正，因此一次全市场事件通常让各股股息同向改变，但不同个股可能因取整不变或触及下限。科技股总体比能源股更敏感。最终价格反应仍可能不同，因为持仓、报价和其他叠加消息不同。

原有普通路径的股息最低为零：若负变化会越过零，则截断到零。原有普通路径没有股息上限、自动均值回归或预设牛熊趋势。v7 另叠加候选/大龙额外股息路径；这部分的增长和回落不改变原有新闻的计算基数。幅度基数最低保留初始股息的一半，因此股息降为零后仍可被好消息抬起；低股息、低价格股票容易产生很大的相对涨幅。标准差不是“价格涨跌上限”，正态抽样也没有硬性的两倍/三倍标准差截断。

**新闻直接改变的是未来现金流，系统不会按新闻直接把成交价拉高或砸低。** 新闻为结构化数据：事件 ID、层级、涉及股票、股息变化区间及时间，没有额外的自然语言新闻文本。看消息的 bot 调整下单，其他 bot 也可能只从盘口、成交方向、动量感知变化；价格由它们互相撮合形成。

当前 `growth` 模型给每股增加独立经营更新机会：平静时每 1000 ticks 为 3.5 次，动荡时 10.5 次，零变化不发消息。局部经营阶段每约 250–900 ticks 切换。三个候选前 1/3 都有温和成长，之后仅指定者继续向随机晚期成长目标发展，叠加经营波动、阶段回落与随机急挫。附加部分的正向单步对数增量上限随机取配置上限 0.16 的 60%–100%，对应约 10%–17.4%，并非每次固定增长；需求不足时实际变化更小或为负。此上限仅适用于“初始＋额外股息”，不限制普通新闻或成交价。普通路径仍独立生成，因此未修改原有普通冲击样本。

以下是历史 3000 ticks v7 的 40 世界实测，不代表当前长局的事件总量：普通三层新闻每局平均 106.63 条，全市场约每 28.1 ticks 一条，每股涉及约 20.89 条；加入当时的小幅经营更新后，全市场平均 459.50 条，约每 6.5 ticks 一条，每股约 56.18 条，即约每 53.4 ticks 一次。这是总体平均，不是固定发布日历；普通重大新闻的频率和幅度没有改变。当前 v18 长局中，tick 3333 后指定者的增长倾向才开始与其他候选分化，不在该 tick 直接跳高股息。v8 的时长选择见 [v8 报告](baseline-v8.md)，新版消息和成长形态见 [v9 报告](baseline-v9.md)，历史 E1 末段急涨解释见 [v7 报告](baseline-v7.md)。

## 首次披露、公开、生效是不同时间

以事件生成于 t 为例：

| 时点 | 发生什么 |
|---|---|
| t | 约 5% 账户收到第一阶段私人区间 |
| t+30 | 累计约 25% 账户知情；先前知情者也收到第二阶段更新 |
| t+60 | 所有账户收到公开的精确变化量 |
| t+120 | 普通股息实际切换到新的金额 |

5%/25% 是每账户抽签概率与累计覆盖比例，不是严格挑出固定人数。早期区间宽度分别为该股本事件冲击标准差的 3 倍、1.5 倍，包含真实变化，且各账户看到的区间位置不同；第二阶段更窄，但不是强制嵌套在自己的上一阶段区间里。

账户组可以显式配置 `news_multiplier`，默认 1；私有阶段累计概率变为 `min(基础概率 × 倍率, 1)`。当前 v18 所有背景账户（含 Titan、Horizon、Lattice、Almanac 和 Osprey）均为 1；Horizon 的额外研究是另一项权限。历史 Titan 挑战实验中的额外账户为 10，即首阶段 50%、第二阶段累计 100%，其余时点和精度不变。`Start.news_multiplier` 告知本人这一权限，基础概率继续由 `Rules.news_stages` 提供；赛后账户记录保存倍率和各阶段投递次数。

另可设置 `forecast_access = { horizon=1000, coverage=0.5, range_width=3.0 }`：独立抽签额外覆盖约一半合格事件，提前量随机为 121..1000 ticks，变化区间宽度为事件标准差的三倍。旧配置和旧 Start 省略此对象时关闭。`forecast=true` 表示额外研究，不计入普通阶段次数；后续公开与实际派息生效时间不变。为保护前段大龙身份，原最早披露在 tick 3333 及以后的全部消息，远期研究也不能在 3333 前送达；该边界跟随场景的 `world.dragon.start_fraction`，旧场景默认 55%。各参数可以单独改变，额外权限不改变世界真值或其他账户消息。

历史普通新闻例子：seed 7 的能源行业事件（旧录制编号 2） 在 tick 81 首次披露、141 公开、201 生效；E1/E2/E3 变化分别为 −9/−10/−4 单位，即每股每 tick 少 0.18/0.20/0.08 分。能源股可能在 81 或 141 附近提前交易这一变化；此前不能把未来的新股息当成当前派息额。

消息和结算跟随每个账户的个人 tick；有暂存回报时，下次决策会收到累积消息。不是要求全市场每个账户在同一个墙钟瞬间同时收到。

## 股息与组合奖励

比赛执行 tick 0–9999，普通股息在 1–9999 每个个人 tick 派发。对每个账户、每只股票，用当时已入账持仓乘当时生效的股息率，然后四舍五入到分，不逐股取整，也不积累余数。仍接受异步成交入账带来的少量多派/少派；没有全市场统一登记、派息暂停或自动除权改单。

组合也在个人 tick 1–9999 逐 tick 结算，共 9999 次。当前都是 1 股 A 配 1 股 B，完整套数为 `min(A股数, B股数)`，每条规则先合计整仓套数再四舍五入到分；同一股票可用于其适用规则，不销毁库存。

| 组合 | 每完整一套、每 tick 的取整前额外现金流 |
|---|---:|
| T1 + T2 | +0.4 分 |
| C1 + C3 | +0.4 分 |
| T3 + E2 | +0.5 分 |
| E1 + C2 | +0.3 分 |
| T4 + E3 | **−0.4 分** |

这些配对和奖金不随种子或新闻改变。组合独立使用 `combo_scale=50`，配置整数单位为 1/50 分/套/tick。例如同时持有 T1 10 股、T2 6 股，每 tick `6×0.4=2.4 分`，取整为 2 分。一套为 0 分，不积累余数；负值对称取整，−0.5 分为 −1 分。实际累计组合收益受持仓路径影响；还有下面的期末组合兑现，所以不同种子的组合总收益可能不同。

普通股息和组合奖励由系统账本支付，负组合收益和费用由账本收取；不要求另一个 bot 同时支付这笔分红。全市场玩家利润不能简单理解为纯粹互相转移的钱。

## 期末兑现与信息

期末期限范围按整局的 1/6–5/6 计算，四舍五入成 50-tick 单位。当前 10000 ticks 从 33–167 中抽一个整数 N，**全市场共用**，不直接告知 bot；平均兑现期限 5000 ticks。tick 0、3333、6666，每个账户分别收到包含真实 N 的私人区间，宽度依次为 100、53、20；区间位置随种子、账户变化。时间与宽度都由比例解析，改成 3000 ticks 时恢复范围 10–50、提示 0/1000/2000 和宽度 30/16/6。

期末单股普通现金流估值约为 `最后生效的每 tick 股息 × 50 × N`，按持仓汇总并四舍五入；再加上 `期末完整组合套数 × 每套每 tick 奖金 × 50 × N`，每条规则汇总后取整，负组合也参与。终值不会重复使用局内单 tick 已取整的金额，故小仓位局内领零不表示终值也为零。最终权益为现金加这笔终值，按相对于初始权益的收益率排名，不按最后成交价卖出所有股票。

例如最后 T1 股息仍为 2 分/tick，N=50 时单股普通终值为 50 元，N=100 时为 100 元。同样 1 套 T1+T2，组合终值分别为 10 元或 20 元，虽然组合每套每 tick 奖金始终是 0.4 分。

终值冻结在 tick 9999 已生效的股息，不继续模拟结束之后的新闻路径；已生成但届时尚未生效的新闻，不提前计入这项终值。当前使用 `terminal_ratio_range` 与 `terminal_hint_fractions`；不能同时指定旧的绝对 `terminal_payments` 或 `terminal_hints`，防止静默覆盖。旧场景的绝对规则仍保持不变。

## 交易、费用与运行

- 10 个连续限价订单簿，价格优先、同价按入簿顺序；按挂单价格撮合。支持 GTC/IOC 限价单、市价 IOC、撤单；买入可部分成交，最小数量 1 股、最小报价单位 1 分。卖单受可卖库存约束，不能裸卖空；同一账户不能与自己的挂单成交。没有百分比涨跌停限制。
- bot 观察十档盘口、最近成交、自己的资产/回报及所获消息。资金、报价和股票流通量主要由账户构成；系统不另设一个无限供给的做市商。
- 买卖双方各付成交额 5 bps，即 0.05%，按每笔成交向上取整到分。每 50 ticks 按该期平均权益的 0.6% 收取闲置费，可用该期符合条件成交额的 1% 抵扣，当前 maker/taker 都可抵扣；不是只按闲置现金收取。完全抵扣需要当期合格成交额达到平均权益的 60%。
- 融资允许现金为负，正常最大持仓杠杆 4 倍，超过 5 倍维护线会尝试强平；借款每 50 ticks 按平均借款额收 0.3% 利息。账面权益/风险使用 20 tick 成交量加权标记价格，窗口空时回退最近成交价。策略可以使用更低的杠杆上限。
