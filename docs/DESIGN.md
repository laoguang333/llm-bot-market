# 设计说明

## 目标

让多个 LLM 各自写只为自己赚钱的 bot，放进同一个市场里对抗，观察行情（趋势、波动、泡沫）能否从策略博弈里长出来，而不是照着真实行情去设计 bot。

所以市场本身要尽量"中性"：没有特权做市商，没有为了产生行情而写死的行为。引擎只提供撮合、结算、信息和一个逼大家交易的理由。

## 每 tick 的顺序

1. 新闻生效：到期的事件改变股息。
2. 新闻披露：按时间表把事件告诉新的一批账户。
3. 派息（到了分红周期）。
4. 把观察发给所有空闲的 bot，等待答复。
5. 按随机顺序（由种子决定）依次执行每个 bot 的动作，每个动作立刻撮合。
6. 记录每个账户的现金，到了费用周期末结算持有费。

所有 bot 看到的是同一个 tick 开始时的盘口，执行顺序每 tick 重新随机，谁也不会固定地抢在别人前面。

## 四个要注意的地方和对应的参数

### 1. 对敲刷成交额

禁止自成交只能挡住同一账户。两个互相配合的 bot 可以来回买卖，用成交额抵扣持有费。目前的防线：

- `rules.stp_scope = "owner"`（默认）：同一作者的所有 bot 之间直接不成交，同一个 LLM 写的多个 bot 无法互刷。
- `fees.trade_fee_bps`：每笔成交双方都付费。对敲省下的持有费是 `成交额 × credit_ratio`，付出的是 `2 × 成交额 × trade_fee_bps / 10000`。把交易费调高可以让对敲不划算，但也会让正常交易更贵。
- `fees.credit_side`：可以只给挂单方（`maker`）或吃单方（`taker`）算抵扣。
- 盘口是公开的：一方挂出来等配合方来吃的单子，任何人都可以抢先成交。

还没有挡住的：不同作者之间私下串通。真正比赛时，作者之间是对手，串通的动机不大；如果出现，可以在结果里按交易对手统计成交额来发现。

### 2. 持有费带来的单边方向

现金一直被扣费，股票有股息，所有人都倾向于把现金换成股票，价格会被推高。这是规则造成的方向，不是策略博弈出来的。目前的处理：

- `carry_rate`、`credit_ratio`、股息和 `discount_rate` 都可调，可以用 `--set fees.carry_rate=0` 做对照。
- 费用进入国库（等于销毁），市场里的总现金会慢慢变少，对价格有反向的压力。
- 报告里画了 `股息 / discount_rate` 的参考价，方便看价格是否系统性地偏离。

### 3. 趋势需要信息源

如果股息完全平稳，聪明的 bot 会很快收敛到合理价，盘面只剩噪音。所以股息只通过新闻改变，新闻按 `world.news.stages` 分批披露：

```toml
[world.news]
events_per_1000_ticks = 4          # 每只股票的新闻频率
change_sd = 0.15                   # 每条新闻的股息相对变化
lead_ticks = 120                   # 首次披露到生效的间隔
stages = [[0, 0.05], [30, 0.25], [60, 1.0]]  # [距首次披露的 tick, 累计知情账户比例]
```

每条新闻的知情顺序是独立随机的，没有永远的内幕账户。新闻在生效前一定已经公开，所以"提前知道"的优势只在窗口里。

### 4. 多轮迭代

bot 在一局里是静态的。真正的对抗要多轮：每局结束后，LLM 看自己的成绩和公开数据（`trades.csv`、`bars.csv`、`news.csv`），改策略再投放。这一部分（比赛编排、跨局排行榜）还没有做，现在的输出已经包含它需要的数据。

## 沙盒

- 每个 bot 一个进程，JSON 行协议，`setrlimit` 限制内存和总 CPU 时间。
- 每 tick 有答复时限，超时只影响自己。慢 bot 不会拖慢市场。
- 这是公平性和健壮性的隔离，不是安全沙盒：bot 仍然可以读文件、联网。跑不可信代码要放进容器。
- 超时取决于机器速度，所以只有在没有 bot 超时的情况下，同一种子的结果才能逐笔复现。

## 结算

- 金额是整数分，股数是整数，交易费向上取整，持有费向下取整。
- 买单按"限价 + 每股最大交易费"冻结现金，成交价只会更好，所以成交时现金一定够。
- 国库收取所有费用、支付股息，`账户现金之和 + 国库 = 初始现金` 和股票总数不变每 100 tick 检查一次。

## 基线结果怎么看

基线 bot 只是对照组。用它们跑出来的行情说明不了"LLM 策略博弈会产生什么"，只能说明机制能跑通。例如基线里价值投资者资金不够，压不住趋势跟随者，价格可能长时间偏离参考价。
