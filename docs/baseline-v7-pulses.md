# v7 阶段跳升版（归档）

本页记录已被趋势版替代的阶段跳升实现，配置归档为 `baseline-v7-pulses.toml`。以下“当前”均指本次历史实验。复现单局时使用归档场景；文末 `research_v7.py` 已固定读取该归档，不再读取当前默认场景。新机制及当前成绩见 [趋势版报告](baseline-v7.md)。

当时默认场景为 `scenarios/baseline.toml`，与 `baseline-v7.toml` 相同。在 v6 背景上增加一个 `titan-value`：初始现金 200,000 元、每只股票 200 股，均为标准账户十倍；新闻倍率明确为 1，正常缴纳每 50 ticks 平均权益 0.6% 的闲置费，成交抵扣规则不变。没有给它免税、额外消息或新参数，也不要求它打穿基准。

因此背景变为 **99–223 个账户、12 种策略、13 个账户组**；seed 7 为 147 人。两个 Swift、6–16 个 NewsV2 和其余 v6 成员保留；Astra 与 Falcon 仍不加入。Titan 是新闻估值、市场定价适应和订单流辅助的分批调仓策略，详见 [Titan 研究](titan-v6.md)。它没有针对新机制识别“大龙身份”的代码，只会看到已交付的新闻及行情。

## 大龙到底改变了什么

每局抽一次，有 50% 的概率指定**一个**潜在大龙；另外 50% 没有指定大龙。普通随机新闻仍然可能令其他股票自然大涨，所以“只有一个指定大龙”不等于“只有一只股票能大涨”。系统不会规定成交价或强制买卖。

每局从十只股票等概率抽取三个候选。候选有相似的早期经营改善与回落，有大龙和无大龙的世界都发生这些候选周期。若抽中大龙，从三个候选中等概率选一只在后期继续增长。候选名、大龙名、未来路径不放进 `Start` 或 `Observation`。

引擎先生成原有三层新闻及其普通股息路径 `B(t)`，再独立生成非负的额外股息率 `G(t)`。实际每 tick 股息率为 `B(t) + G(t)`。这不是乘股价的系数，也不是一次性奖金；额外部分和原来普通股息一起按账户整仓取整、逐 tick 发放，最后生效的总股息也参与原来的期末兑现。没有额外除权逻辑或费用豁免。

下表中的倍数均以该股**初始股息率**为单位；时间为首次披露，公开和生效仍分别延后 60、120 ticks。

| 阶段 | 默认 3000 ticks 世界中的规则 |
|---|---|
| 三个候选的前期路径 | 首次披露分别抽在全局 20%–27%、33%–39%、44%–49%；额外股息依次约 +0.20–0.35、+0.40–0.65、+0.15–0.35 倍初始股息 |
| 身份信息开始分化 | 不早于全局 55%，即 tick 1650；同种子有/无大龙的账户消息和股息在此之前完全相同 |
| 大龙后期路径 | 五次调整：峰值的 40% → 峰值 → 峰值的 35%–55% → 70%–95% → 50%–95%；峰值额外股息为初始股息的 2–4 倍 |
| 非大龙候选后期 | 额外部分从早期回落后的水平逐步降到零，最后恢复原有普通路径 |
| 后期时间 | 五次首次披露在 tick 1650 到最晚可生效时点之间的五个分离随机窗口；全部在本局结束前生效 |

若原有普通股息恰好不变，大龙的峰值总股息约为初始的 3–5 倍。普通新闻可能另外改变总额，因此这不是总股息的固定上下限；额外部分有明确回落，并不保证每次总股息都同步下降，也不保证高收益或上涨价格。

`world.dragon` 提供 `enabled`、`probability`、`candidates`、`peak_extra`。默认关闭以兼容旧场景；启用时需要至少两个候选，并满足 `ticks > 3 × lead_ticks + 30`，给分阶段披露和生效保留时间。公开 `Rules.dragon` 只含概率、候选数、信息分化起点和峰值分布，不含抽签结果。

## 新闻、复盘和信息边界

新增事件与普通个股新闻使用同一个 `NewsItem` 格式，同样在私人阶段给区间、公开时给精确 delta、生效时切换股息。额外事件的区间尺度为 `max(|delta|/2, 初始股息 × 普通个股冲击标准差)`，再乘既有阶段宽度。该尺度是机制公开规则，不是额外信息权限。

普通消息的随机抽样键与公开事件编号分离：插入新增新闻后会重新按时间编号，但不会改变原有新闻的冲击数值、原有账户谁提前获知、区间内容、开局价格、市场状态或终值抽签。新增 Titan 位于最后，也不改变原有账户的编号。对照中的真实交易与行情仍会变化，多线程比赛不要求逐笔复现。

身份的完整隐藏期严格覆盖前 55%：即使某账户能收到全部私人消息，也无法从这段已经交付的信息区分同种子的“候选最终继续增长”和“候选最终全部衰退”。前期可识别经营改善候选，后期可逐步判断持续性。没有声称 55% 之后仍不可识别，也没有声称种子不可推导；审查仍禁止策略重建隐藏世界。

每局结束后 `summary.json` 新增 `dragon`：候选股票索引、选中股票或 null、分化起点、每次额外股息调整。索引对应场景股票顺序。`news.csv` 保留所有新闻及披露/公开/生效时间，`bars.csv` 含实际总股息，成交与账户报告照常生成。这些是赛后真相，不能供正在比赛的 bot 读取。

## 固定实验与审查

预先固定种子 27001–27040，共六组、240 局，每世界每组一次；release、4 个市场线程，Windows 共享 10 逻辑核预算，经过 `arena_gate.py` 串行执行。六组为 v6、加入十倍 Titan、改为一倍 Titan、只有候选周期且无后期大龙、完整机制十倍 Titan、完整机制一倍 Titan。所有组正常缴费、普通消息权限，不以这些结果调策略参数。

收益按每世界每策略的账户平均再跨世界平均，避免人数较多的世界权重更高；两个 Swift 分开。除了全机制对照，也只在实际抽中大龙的配对世界中比较“完整机制”和“候选全部衰退”，避免把所有收益变化归因于后期大龙。资金实验每局只有一个 Titan，替换其资金规模，不放两个 Titan 互相争抢。改变初始资金和股票也会改变流通量及其他账户的交易，不能解释为纯粹固定行情的下单容量测试。

策略生产代码没有改动。Titan 与 `Knowledge`、`hold_value`、`requote` 的既有审查见 [Titan 文档](titan-v6.md)，其他背景成员见 [v6 审查](baseline-v6-bot-review.md)及 [NewsV2 替换记录](baseline-v6-current.md)。本轮重新核对 Titan 仅使用 Rules、本人观察和已收到消息；没有读取 `Rules.dragon` 作专门预测，没有隐藏世界/文件/网络/种子推断入口。冻结源码哈希和原始运行保存在 `runs/v7-dragon-study`。

新增机制测试验证了前中期消息隔离、基础新闻及私人披露不变、概率抽签、公开字段、延后生效、额外股息非负、回落恢复和旧 Rules JSON 兼容；原有撮合优先级、待入账成交、股息与费用、消息投递、现金/股份守恒测试继续运行。短时调度测试明确固定到归档 v6，避免默认世界改变它们的测试条件。

## 40 世界、240 局固定结果

40 个独立世界中有 16 个抽中指定大龙，其余 24 个只有候选经营周期。这是 50% 概率的一次样本，不强行凑成一半。各组使用相同世界种子，不代表多线程成交逐笔相同。

### 各策略在完整新机制下的变化

下表两组都有同一个十倍资金、普通权限 Titan。左组完全关闭候选/大龙，右组开启完整 50% 机制。收益包含股息、组合、交易和库存估值并已扣费；排名为收益率百分位，越高越好。

| 策略 | 关闭机制平均收益 | v7 平均收益 | 关闭机制平均百分位 | v7 平均百分位 |
|---|---:|---:|---:|---:|
| swift-early-single | +130.44% | +162.35% | 98.95 | 98.20 |
| swift-standard | +109.51% | +139.21% | 96.03 | 96.32 |
| titan-value | +43.89% | +68.20% | 82.47 | 83.75 |
| hunter | +59.50% | +85.54% | 83.49 | 82.20 |
| coral | +29.27% | +44.52% | 76.34 | 75.23 |
| news_v2 | +30.91% | +52.97% | 69.85 | 73.26 |
| value | +15.22% | +32.71% | 69.27 | 70.45 |
| momentum | +8.10% | +19.92% | 62.59 | 62.20 |
| shark | +5.28% | +14.94% | 54.50 | 54.77 |
| tracker | +12.23% | +15.85% | 56.15 | 54.66 |
| hold | -22.96% | -18.50% | 40.56 | 41.93 |
| noise | -33.52% | -32.44% | 30.76 | 30.89 |
| grid | -47.28% | -51.68% | 15.51 | 13.96 |

完整机制提高了多数策略的平均收益，但没有让它们同时提高相对排名。十倍 Titan 收益增加 24.31 个百分点，排名只增加 1.28；Coral 收益上升，平均百分位却略降。Grid 的平均损失扩大 4.39 个百分点。其买跌卖涨、延迟重设网格的行为与持续重估及大幅回落不匹配是一种合理解释，尚未通过逐笔归因证明。

只看同样抽中大龙的 16 个世界，与“同候选、但最终全都衰退”对照，后期大龙令 Titan 平均收益增加 39.68 个百分点，early-single 增加 33.24、普通 value 增加 24.34、NewsV2 增加 20.74；Grid 减少 5.07。普通 Swift 为 +19.77，但此小样本的配对近似 95% 区间跨零，不能把它单独写成稳定的后期大龙收益。完整逐策略差值与区间保存在 JSON。

全市场按初始权益加权的收益从 −17.95% 变为 −13.40%，仍为负；持有型 hold 从 −22.96% 变为 −18.50%。额外现金流改善了整体收益，交易、闲置费用及有限期终值仍有影响。强策略的较高收益不能直接等同于全市场都盈利。

### Titan 资金容量

| 同一 Titan 策略 | 十倍资金 | 一倍资金 | 一倍更好的世界数 |
|---|---:|---:|---:|
| 关闭候选/大龙，平均收益 | +43.89% | +98.79% | 35/40 |
| 完整机制，平均收益 | +68.20% | +144.12% | 35/40 |
| 关闭机制，平均排名百分位 | 82.47 | 86.93 | 31/40 |
| 完整机制，平均排名百分位 | 83.75 | 88.92 | 32/40 |

完整机制下十倍 Titan 有 5/40 局亏损，一倍有 2/40。小资金提高收益率的证据较强，但不是每局都优于大资金。正式基准仍保留十倍账户，一倍仅为实验对照。

收益拆分表明，不能把容量差全部解释成“买卖价差更好”：关闭机制时，一倍相对十倍的股息贡献增加 55.82 个百分点，交易及库存估值贡献差仅 +3.54 且配对区间跨零；完整机制时对应 +63.96 和 +18.15，后者区间仍跨零。较小账户每单位权益成交更多，能够形成不同持股路径；流动性、整股取整、费用抵扣和改变全市场供给均在作用，尚未逐一拆开。

在一倍 Titan 所在的两组里，它的平均收益和平均百分位都高于所有非 Swift 策略组，两个 Swift 的平均成绩仍更高。这个结果支持它比旧 value 更强，但没有证明逐局优于每一个旧 bot，或任意资金规模、任意市场下都成立。

### 验证、市场异常与性能

103 项 Rust 测试和严格 Clippy 通过。240 局共 1440 次现金/股份审计，全部账户零跳过、零 bot 错误、零停用。正式 v7（十倍 Titan）40 局无强平；关闭机制的十倍组有一次 tracker 强平、无坏账。一倍资金机制对照组有两名 tracker 共四次强平，并产生合计 1879.80 元坏账核销；这些不是 Titan 强平，仍按市场风险保留记录，没有删除异常世界。

市场质量全项通过：历史 v6 31/40，加入十倍 Titan 后关闭机制 27/40，完整 v7 31/40，一倍资金完整机制 33/40。v7 的失败项目为双边报价不足 1 局、估值偏离 3 局、价值穿越不足 6 局（项目可重叠，总失败 9 局）。各组的逐局双边报价率中位数均约 99.67%。没有放宽质量门槛，也不把“基准已建立”解释为所有市场指标通过。

性能独立串行测量：release、4 工作线程、Windows 10 核共享预算；种子 7/11/19，每场景每种子 3 次，各场景先预热。旧引擎运行 v6 的进程墙钟中位数 1.325 秒，新引擎同配置 1.308 秒，未测到明显回退。新引擎只加入 Titan 为 1.354 秒，完整 v7 为 1.342 秒。这里三个预定种子恰好均未抽中大龙，仍包含候选周期，不能只用这组估计实际大龙路径的性能。

因此补测固定 40 种子中最早抽中大龙的 27003/27006/27007，每组每种子 3 次、交替串行：关闭机制 1.367 秒，开启机制 1.384 秒，中位墙钟约增加 1.24%；引擎内计时为 1.250 → 1.253 秒。该比较包含交易行为变化，不能当作纯世界生成开销。没有降低任何策略决策频率。

另用种子 7/11/19、单线程，旧二进制和新二进制各跑一次冻结 v6，成交 CSV、新闻 CSV、全部账户现金/股份/期末权益及消息计数完全一致。性能与兼容性共 64 局，和前述 240 局策略实验分开，不算新增独立世界。

### 一个可复盘的大龙世界

种子 27003 的三个候选为 E2、C2、E1，最终大龙为 E2。E2 的额外股息率在 tick 2067 生效为 310 单位，即每股每 tick 额外 6.20 分；tick 2402 回落到 148 单位（2.96 分），2587 恢复至 244（4.88 分），2899 调整为 232（4.64 分）。实际派息还要加上同一时点的普通新闻路径。
