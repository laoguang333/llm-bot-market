# v21：分红风险校准与竞争策略实验

本轮检验三个问题：Tide 的恢复估值和闲置费抵扣各有多大作用；v20 的分红压力是否过强；有风险折扣的价值投资者和库存做市商能否改善生态。固定组合现金流、终局、费用和融资规则保持不变。

**结论：世界路径校准通过，新策略生态验收失败，不晋级默认。** 本轮完成 136 局、2,720 次守恒审计，零 bot 错误、禁用或跳过；默认仍为 v18。降低 Tide 收益没有带来更健康的市场。

方案、种子和验收条件先登记于 [事前协议](ecology-v21-protocol.md)。[运行前审查](ecology-v21-review.md)覆盖新策略的信息权限、现金预约、库存和订单限制。Harbor / Relay 继续作为可独立运行的实验实现保存。

## Tide：恢复估值的作用比抵扣交易更明显

v20 压力世界 90001–90006，每世界重复两次，每个方案 12 局。只改变 Tide 的既有公开参数；其余账户和初始资产相同。

| Tide 方案 | 平均净收益 | 盈利局数 |
|---|---:|---:|
| 完整版 | +356.66% | 12/12 |
| 恢复目标设为零，沿用当前分红估值 | −17.29% | 5/12 |
| 禁用抵扣交易 | +299.60% | 12/12 |
| 两者都关闭 | −29.00% | 2/12 |

恢复估值带来的收益差在六个世界中方向一致；保留恢复估值时，抵扣交易的增量在四个世界为正、两个为负，平均为 +57.06 个百分点。关闭恢复估值时，抵扣交易的平均增量为 +11.71 个百分点。这是小样本的策略整体消融：更改估值会改变建仓、杠杆、再平衡、组合收入和市场竞争，不能解释为一笔独立、可叠加的“预测利润”。重复比赛属于同一个世界，不是新的独立世界。

Tide 并非被证明“知道一定恢复”，也不是纯买入持有。结果说明这种乐观估值驱动的持仓，在这些内生价格下仍有明显竞争力。固定组合未做开关实验，不把总收益归因于组合。原始账目见 [Tide 结果](ecology-v21-tide-results.json)。

## 新策略与资金约束

- **Harbor**：根据当前分红、可见历史高位和公开风险分布估计剩余现金流。历史高位只是有折扣的参考；严重削息可能长期不恢复。已收到的消息按生效时间计入，期后变化不进入终局。它不是隐藏状态识别器，也不是在线学习模型。
- **Relay**：根据盘口价格、价格波动、收到的分红消息和本账户库存调整买卖报价。库存高时降低报价中心，波动高时扩大点差；普通股息为零时仍出售已有库存。买价受现金流估计约束，不保证持续接盘。
- 两者都保留固定组合的库存边际价值，处理组合单位和生效区间；禁止新建负组合两腿。总买单受现金、现有预约和缓冲约束，不使用同批卖出收入。撤单后等待新观察再挂同侧，明确承担由此造成的报价间断。
- 对应替换匿名 Value / Coral 群体，原位置、人数、逐账户现金/股份、消息权限不变；资本再分配的策略键同步改名。命名强 bot 全部保留，没有额外注资。

两策略自行选择每 5 ticks 重报，未降低任何旧 bot 的决策频率。引擎仅在原有盘口采样循环中增加股数累计，不改撮合、消息或结算。

### 强 bot 的连带影响

同一独立组，原阵容 → 双替换的平均净收益：Tide +516.41% → +432.33%，Almanac +539.63% → +511.29%，Horizon +395.71% → +501.73%，Titan +149.12% → +322.79%，Kestrel +39.34% → +194.69%，Lattice +57.12% → +84.62%，Osprey −8.14% → +50.31%。不同优势受益或受损，并没有一起变弱。

Swift 尤其受损：standard 从 +39.41% 降到 −78.80%，early-single 从 +157.33% 降到 −24.68%。后续已补充 [Swift 逐笔与参数消融诊断](swift-v21-diagnosis.md)：成交对手结构与可兑现的短线优势改变，standard 持续调仓进一步放大损失；单独删除深度或动量项没有稳定救回。Horizon 的十倍资本与额外研究权限也始终保留，不能将其排名当作普通账户能力的公平横比。

## 失败来源与下一步

独立组 Harbor 的成交金额仅为初始权益的 1.20 倍，Relay 为 1.61 倍；现金闲置费分别达到初始权益的 71.61%、76.72%。Harbor 大量卖出后缺少重新买入，Relay 也没有形成有效库存循环。策略本身失败，现有费用进一步放大这种失败。

不能把责任全推给费用：同批原 Value 平均 −3.46%、Coral −43.36%，都好于对应替代者。现金闲置费是账目的主要负项，不等于已证明“关掉费用后这些 bot 就能赚钱”；费用变化会反过来改变报价、持仓和竞争，需要独立消融。详细分组现金流、成交与耗时见 [账目汇总](ecology-v21-accounting-results.json)，由 `tools/summarize_ecology_v21.py` 从已冻结原始输出生成。

仅从规则算术看，完全不交易、没有收入的纯现金按每 50 ticks 的 0.6% 扣费，200 个周期后约损失 70%。因此“卖出避险后等机会”不是低成本行为。下一轮应优先对现金闲置费与成交抵扣做独立实验，检验市场是否在过度奖励周转/抵扣行为；同时修复新策略的再入场与库存周转，而非继续增加同类谨慎账户。

还有一个需要单独检验的开盘锚：`world.rs` 仍以初始分红延伸乘剩余支付期数产生参考价格，没有纳入新增的分红风险分布。这影响初始权益与收益率口径，但降低开盘估值本身不创造现金收益。应同时核对实际现金收支和库存，不能用修改分母宣称市场变健康。

本轮没有修改费用、开盘锚或组合合同，没有根据独立组结果调整新 bot，也没有把较温和世界单独晋级默认。

## 诊断口径

旧 quality 输出完整保留。新报告按采样 tick 的生效普通分红分类：高于初始 25%、低正分红、零分红，并额外合并后两类。每 10 ticks 采样；在各局内汇总股票样本，再对比赛等权平均。缺少某状态时不填零，报告实际局数和采样数。

买/卖/双边覆盖、2% 范围内薄侧股数及金额深度、所在 20-tick 桶是否成交、双边条件下平均相对点差分别报告。深度继续使用原采样最多 100 档的限制；缺边时薄侧深度为零。没有把当前普通股息延伸或隐藏未来分红当作统一“正确价格”，组合的边际价值因库存而异。

市场收益账目使用精确现金恒等式：普通分红 + 组合分红 − 现金闲置费 − 交易费 − 利息 + 坏账豁免 + 终局价值 − 初始股票价值。股票闲置费另列，它烧掉的股份已影响终局，不再次从现金恒等式扣除。群体净收益以群体总初始资本为分母，再跨局等权平均；正百分位不等于盈利。
