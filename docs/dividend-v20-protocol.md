# v20 分红风险：冻结实验协议

目标是取消机械抄底的恢复保障，而不是指定 Tide 输赢。普通分红下限为零，只有分红历史、消息变化区间、原有研究权限与交易信息对 bot 可见，不增加经营报表或公司类别字段。

## 机制与兼容性

`world.dividend_risk` 为显式开关，缺省继续使用旧世界，v18 与 v19 归档场景不改。普通消息改为均值保持的乘法冲击，去掉初始分红一半的冲击下限；在零点不靠截断负数制造向上反弹。独立的逐股分红保留率作用于普通路径和整个成长增量，成长股也没有豁免。每隔局长的 12%–28% 复核一次：正常派息时 22% 概率减息、6% 概率停息；受损或停息时 18% 概率改善，另有 6% 概率停息。其余概率保持状态。

减息保留此前正常水平的 2%–30%；改善后保留此前正常水平的 35%–85%。从停息恢复时先回到受损水平。复核不保证恢复，反复受损可以永久下移中枢。变化在局长 2.5% 的时间内分四次释放，均走原有私人区间→公开精确值→生效的消息管线。区间仍是**单个事件的分红变化上下界**，不改称未来整段分红水平的置信区间，也不制造失实消息。

终局规则保持原合同：最后生效普通分红乘隐藏期限；停息的普通终值为零，结束后才生效的消息不提前计入。没有额外的恢复估值或初始分红保底。原组合现金流是独立合同，继续支付或扣款，因此停息不等于公司破产或所有持仓价值归零；本轮不借机改变组合、费用、借款、撮合和决策频率。

公开 `Rules.dividend_risk` 只含过程参数。实现仅依赖配置、世界种子和原分红事件，不读取账户、价格、持仓、排名或策略名。先生成、再按实际支付路径重算每个消息 delta，保证消息能重建真实非负分红。不同账户人数或信息权限不改变路径；成长身份披露禁运继续有效。

## 验证与冻结

新增测试覆盖参数校验、长期零分红、零点无自动反弹、消息重建与区间包含真值、缓存一致性、信息权限隔离、成长披露禁运、恢复与不恢复并存、逐 tick 现金与股份守恒及终局结算。保留现有撮合优先级、消息投递测试。

既有 bot 生产代码与 `694183c` 对比必须无变化，沿用已审查实现；仅三个测试构造器补入公开规则字段。未根据这轮结果修改 bot。新增测试里的 Holder 只返回空动作，已经人工审查。

在查看收益前冻结本协议和唯一参数组。世界形态样本 89001–89100，各 10 只股票；开发比较 89201–89210，每世界两次，v18 对 v20，共 40 局；独立验证 89301–89310 同样 40 局，参数不调优。额外在 89401–89403 各重复两次，比较原 v19 balanced 与加同一分红机制的版本，共 12 局，仅检查交互。v19 既有 87001–87020 留出不使用。不同阶段原始结果分别保存，不覆盖。

世界形态检查：所有分红非负；至少 10% 股票有连续 1000 ticks 停息；至少 20% 股票期末分红 <= 初始 25%；前半场首次跌至初始 25% 以下的样本中，之后回到 75% 以上者和未回到者均存在，且未恢复者占多数。该指标是过程校准，不是策略成绩。

晋级默认需开发与独立验证分别满足：零 bot 错误、禁用和跳过；全部守恒审计通过；市场质量通过率至少 80% 且不低于同批对照；双边覆盖下降不超过 2 个百分点；薄侧 2% 金额深度不低于对照 70%；中位点差不高于对照 1.5 倍；Grid 平均毛亏损份额不超过 25%，且相对对照增长不超过 5 个百分点。世界形态也必须通过。未通过保留实验场景与失败报告，不改变默认。Tide 收益下降不是晋级条件。

所有收益按账户初始现金加初始股票市值计算，Swift 两个账户分别汇总。拆分股息、组合、费用、终值及交易/库存残差，不把系统派息等同于弱 bot 的转移支付。原质量中的估值偏离采用当前股息延伸代理，停息资产仍有组合合同，需解释其适用局限，不能事后删门槛。

## 运行

release、4 个市场线程、Windows 10 核共同亲和性预算，arena_gate 串行。记录配置、全部 Rust 源文件、工具及二进制哈希、种子、重复、CLI 和模拟墙钟；方案交替先后。改变分红会改变价格、成交和策略计算量，墙钟变化不称为引擎性能优化。

python tools/build_release.py
python tools/arena_gate.py --cwd . -- python tools/validate_dividend_risk.py shapes
python tools/arena_gate.py --cwd . -- python tools/validate_dividend_risk.py dev
python tools/arena_gate.py --cwd . -- python tools/validate_dividend_risk.py holdout
