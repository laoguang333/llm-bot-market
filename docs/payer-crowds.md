# 五类支付群体

支付者按交易动机划分，实际支付份额通过模拟统计确认，不预设每个账户必亏，也不将费用支出直接当作其他 bot 的利润。

本文描述 v19 实验场景；当前默认仍为 v18。实现、验证结果及未晋级原因见[实验报告](payer-v19.md)。

| 群体 | 注册策略 | 交易动机 | 主要弱点 |
|---|---|---|---|
| 赚钱／亏钱效应组 | `profit_effect` | 自己和同伴的实际盈亏改变投入；少数成员主动追领涨股 | 浮盈传播、跟随和集体退缩 |
| 信息弱者 | `news_reactor` | 夸大公开新闻的影响，以近期印象分配资金 | 忽略早期私有披露，不判断价格已消化多少消息 |
| 噪声交易者 | `noise` | 沿用既有随机交易行为 | 缺少稳定信息优势，承担成交成本 |
| 迟到者 | `latecomer` | 观察到价格移动后形成意图，经过个人反应时间再执行 | 机会和价格在等待中改变，买卖两边都会迟到 |
| 网格组 | `grid_v2`（历史为 `grid`） | 受现金与库存约束的简单网格，逆势交易 | 价格中枢改变后的库存积累和逆向选择 |

ProfitEffect、Noise 实现保持原样。第四轮用独立的 [Grid v2](grid-v2.md) 保留简单网格行为并限制库存风险，旧 Grid 及历史场景保留。机械趋势不再单列背景组，ProfitEffect 已有少数追领涨成员。成本锚定／摊平保留为将来的网格组变体，本轮没有增加该策略。Coral、Value、NewsV2 和各命名竞争者继续参与，不能将它们的收益视作必然盈利。

## 信息弱者

每个账户独立抽取反应强度、记忆、投入意愿和下单约束。只响应普通新闻中已公开的消息，忽略早期私有披露和远期研究。使用公开区间中点除以当前可见股息与初始股息一半的较大者，将变化变成相对刺激。同一事件若有更高阶段的公开修订，替换旧估计并沿用首次注意时间，不重复下注；标准世界仅在最终披露阶段公开。

刺激按实际 tick 差指数衰减，再乘账户的放大系数。每只股票的目标权益权重为 `baseline / 股票数 + amplification × 累计刺激 / 股票数`，限制在 0 到单股上限，总权重超过投入上限则同比缩小。记忆淡去后回到个人中性分配。其弱点是信息定价粗糙，而不是偷看真值后故意买错。

没有新闻时仍保留个人中性组合，会进行一般再平衡；它不是零仓等待消息的纯事件策略。忽略社会盈亏、远期研究、终值提示和订单流。普通新闻权限与其他普通账户相同，正常接收私有区间及公开修订，但主动忽略私有披露；信息劣势来自策略的注意方式，不是额外修改引擎消息权限。

新事件到达时记录该股当前可见成交价作为锚；主观可接受价格为 `锚 × (1 + amplification × 累计刺激)`，刺激对应的价格变化限制在 −35% 至 +60%。同一事件后续修订不重设锚。委托在这个主观价格上再应用个人追价边界，因此错误信息解释能导致过高买价或过低卖价，仍按盘口实际成交，而不会凭空按照委托价多付钱。首次新闻前使用第一次观察的价格作为锚。

## 迟到者

维护个人观察价格的指数均值。当前最近成交价比该均值高出阈值时形成买入意图，低于负阈值时形成卖出意图。意图保存当时的价格、目标股数、最早执行 tick 与失效 tick。延迟期间仍每 tick 决策、观察和检查有效性；不改引擎调度和消息投递。

只有到达最早执行时刻才可下单，买入上限及卖出下限始终以意图形成时的价格计算。窗口过期或出现相反价格信号时取消旧意图。每只股票有个人冷却间隔，避免取消后立即重新生成大量重复意图。反向证据使它放弃过时计划，但不让它提前成交。

买入按当前权益重新限制单股与总投入，不能用旧权益目标扩大风险；部分成交后依据实际持股继续执行差额。卖出目标为零，但受实际可卖数量和价格边界限制。未成交不算退出。不使用新闻、社会盈亏、终值或隐藏价值。

## 参数与执行

范围是每账户开局独立均匀抽样。场景显式参数覆盖该字段抽样；其他字段继续多样化。参数种子只用于个人差异。

| 参数 | 信息弱者 | 迟到者 |
|---|---|---|
| `memory` | 180–600 ticks，新闻印象 | 30–100 ticks，观察价格均值 |
| `amplification` | 3–7 | 不适用 |
| `baseline` | 总权益的 35%–65% | 不适用 |
| `threshold` | 不适用 | 0.8%–2.5% |
| `delay` | 不适用 | 40–160 ticks |
| `patience` | 不适用 | 到期后 30–90 ticks 执行窗口 |
| `cap` | 单股目标 18%–30% | 单股目标 15%–25% |
| `invested` | 总股票目标上限 75%–92% | 总股票目标上限 75%–90% |
| `clip` | 单笔权益 1.5%–3.5% | 单笔权益 1.5%–3.5% |
| `chase` | 主观可接受价格上下 1.5%–4% | 原意图价格上下 6%–15% |

两者共同使用现金预算、可卖数量、动作数和最小价格步长约束。有可接受对手报价时使用有价格限制的 IOC；否则在个人价格边界内挂限价单，有本侧报价时改善一档。每股最多一笔，观察到 20 ticks 后刷新，意图取消或失效也撤单。撤单后的预算到下一次观察才复用。买单逐笔扣减本次可用预算，不预支同一次调用中卖单的收益。非清仓的小于权益 0.25% 的调整忽略。总仓位上限限制新增目标，价格变化或原始持仓超过上限时不假装已经减仓。

新实现独立于旧 bot 策略，未阅读旧策略实现；[运行前审查](payer-crowds-review.md)、[事前实验协议](payer-v19-protocol.md)。

## 统计口径

净收益、费用和股息分别报告。交易／库存／终值残差由最终权益变化扣除股息、组合收益、坏账豁免，再加回交易费、闲置费和利息得到；股票闲置费按当时标记价值加回，因此残差不是纯交易现金流或精确的对手利润。

后半场活跃度统计该群体中在 tick 5000–9999 有实际成交的账户比例。外组成交额排除同策略账户之间的成交；它仍不是盈利转移。

成交后偏移固定取每个账户、股票、100-tick 桶中的第一笔外组成交，不按盈亏挑样本。参考价为成交后至少 20／100 ticks 的第一个 10-tick 双边盘口样本（实际跨度为 20–29／100–109 ticks）。普通股息按逐 tick bars 累积，买入计正、卖出计负，再扣该笔手续费，按样本成交额加权。无双边盘口或临近期末缺少足够未来数据的样本剔除并计数。此项不计组合收益、不计现金闲置费，忽略账户派息取整，是报价偏移诊断，不能解释为实际持有至该时刻的收益。各局指标随后等权平均。
