# v15：大龙成长提前至全局约 1/3

本页记录归档 `baseline-v15.toml`；当前默认已升级为 [v16](baseline-v16.md)。v15 相对于 v14，唯一配置值变化是 `world.dragon.start_fraction = 0.3333333333333333`；保留 102–226 个账户、16 种策略。Tide 与 Kestrel 各一个普通账户继续保留，Osprey 仍在独立研究中。

10000 ticks 的分化起点从 5500 提前到 3333。候选共有的温和成长在此前完成，指定者从这里开始允许持续成长分化。远期研究的身份保护截止点同步修改；不是在 3333 突然跳高派息，经营消息仍不定期出现、最早普通披露后 120 ticks 才实际生效。

成长强度、事件率、回落窗口（全局 67%–81%）、目标高点窗口（87%–97%）不变，因此成长更早、更长。候选早期爬升也会更快，无指定大龙的世界并非完全不受影响。普通三层消息、费用、终值、撮合、个人时钟和决策频率没有修改。旧场景省略参数仍取 0.55，旧脉冲模型仅允许该历史值；公开规则和报告给出实际分化 tick。

## 是否更接近十倍股价

正式种子 72001–72020，每个四臂，共 80 场；其中 11 个有指定大龙。下面只比较同一个旧 Osprey、同位置研究账户的旧/新起点，避免把策略变动混进成长效果。价格由市场交易形成，多线程路径有噪声；股息路径由世界决定。

| 指标 | 均值 | 中位数 |
|---|---:|---:|
| 旧起点：股价峰值/真实开局参考价 | 4.48 | 3.98 |
| 新起点：股价峰值/真实开局参考价 | 4.96 | 4.80 |
| 旧起点：股息峰值/初始股息 | 11.50 | 11.80 |
| 新起点：股息峰值/初始股息 | 12.53 | 13.00 |
| 旧起点：全局普通股息机会，元/股 | 519.76 | 473.86 |
| 新起点：全局普通股息机会，元/股 | 682.59 | 611.15 |

股价峰值达到开局参考价十倍：旧起点 0/11，新起点 1/11。全局普通股息机会的配对增幅平均 +33.09%，中位数 +28.97%，11/11 为正。该机会是持续持有一股的未逐 tick 取整现金流，不含买入成本、费用、组合及期末兑现，不能当作账户收益。

更早成长确实给中段留下更多派息时间，但价格还受剩余期限、隐藏终值提示、供需和策略交易影响。股息目标不是固定十倍，更没有把成交价硬设为十倍。本轮价格统计以真实开局参考价为分母；旧 [大龙机会记录](dragon-opportunities.json)采用首个有成交 K 线开盘价，口径不同，不能直接拼接。
