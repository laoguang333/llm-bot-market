# v22：市场功能、费用与基础生态研究

本轮把“某个强 bot 是否赚钱”与“市场能否持续交易并响应信息”分开。使用 v21 已固定的中等分红风险，不新增经营变量，不修改固定组合、终局、消息窗口、撮合或强平规则。默认仍为 v18。研究配置、工具和阶段结果提交到实际主分支 `main`。

**已完成 256 局、5,120 次守恒审计，零 bot 错误、禁用与跳过。** 降低收费没有使成交和消息响应消失；限制 Coral 杠杆、缩小 Noise 单笔规模带来了跨世界改善。但追加方案开发未通过，独立组仍差 Grid 毛亏损份额这一项（30.48%，门槛 30%），因此未晋级默认、未启动强 bot 回填。独立组的门槛差距很小，不应把它说成市场整体失灵；Grid 本身仍亏损约四分之三，值得继续调查其交易行为。

## 方法与评价边界

新工具 [market_health.py](../tools/market_health.py) 离线读取真实比赛输出，保留旧 quality 九项，增加分状态、分前后半场的流动性和参与者持续性诊断。旧价值穿越、波动聚集和当前股息外推不用于新基础生态晋级；没有修改旧质量输出来制造通过。

- 正常股息、低正股息、零股息分别报告盘口、成交与深度；正常状态为当前普通股息高于初始 25%。
- 同时报告双边覆盖、20-tick 成交桶覆盖，以及双边中价 2% 内各至少 10 股的覆盖，避免一股报价或股价变化掩盖数量不足。深度只是快照，不能保证实际下单时仍能成交。
- 消息响应按首次普通披露对齐，使用明显且窗口内没有其他同股披露的事件，比较披露后与事前含普通分红的价格变化。区间中的报价必须真实存在，不前向填补缺边。生效在终局之后的消息不作目标。
- 报告各组实际成交、maker 份额、后半场活跃度、净收益、分红、费用、融资利息、毁损 90% 的账户比例和股份集中；逐组精确核对现金账本，不重复扣除烧毁股份。

消息响应命中率是选定消息样本的方向诊断，不是全市场“定价准确率”，也不是可兑现收益。统计先合并同世界重复，再按世界等权；同一宏观事件涉及不同股票仍相关，去重的世界/事件/股票数量不冒充统计独立试验数。正负消息、重叠排除及缺报价数量保留在 JSON。

[原协议](ecology-v22-protocol.md)先固定费用矩阵、基础群体、世界种子、门槛及有条件加入强者的程序；[运行前审查](ecology-v22-review.md)记录权限和配置边界。没有用 Swift 收益、市场总收益或支付者亏损额度挑选赢家。

## 费用对照：高闲置费不是维持活跃的必要条件

原完整阵容、同一中等风险世界，91001–91006，每世界两次，每方案 12 局。交易费 5 bps 和融资利息始终保留；变化的是现金和股票共同承担的闲置费及其成交抵扣，不是单独取消现金费用。

| 方案 | 每 50 ticks 闲置费 / 成交抵扣 | 市场净收益 | 正常双边 | 正常成交覆盖 | 正常 10 股深度覆盖 | 股份烧毁 |
|---|---|---:|---:|---:|---:|---:|
| current | 0.6% / 1% | −30.50% | 94.79% | 97.81% | 76.69% | 23.99% |
| light | 0.1% / 1% | +11.92% | 94.61% | 97.66% | 76.36% | 0.99% |
| flat | 0.1% / 无抵扣 | −2.97% | 95.49% | 98.10% | 78.21% | 13.94% |
| none | 无闲置费 / 无抵扣 | +18.37% | 94.73% | 97.97% | 76.33% | 0% |

三种替代收费在六个世界的配对市场净收益上均高于 current。消息响应方向命中率分别为 98.34%、98.09%、97.80%、97.92%，未显示随收费降低而消失的方向反应。这里只研究了六个世界的完整阵容，不能推断任何阵容、任何时长都无需交易动机。

总账户成交额/初始权益为 146.35、153.67、153.43、155.81 倍；金额口径也受价格和存续资产影响，不能单凭成交额说交易功能增强。高收费原本试图迫使交易，同时却烧毁股份并削减后续交易能力；本批数据不支持“收费越高才能越活跃”。抵扣前最后四个 ticks 的成交份额也只有约 7.6%–10.0%，不能将全市场成交笼统称为收费时点刷量。

费用不是全部原因。current → none，Coral 平均 −42.98% → −34.24%，旧 Grid −99.61% → −99.59%，Noise −85.33% → −76.16%；它们仍然明显亏损。Value 从 −12.15% → +93.92%，不同策略承受费用和库存风险的方式很不一样。详见 [费用结果](ecology-v22-fees-results.json)。

## 七类基础生态：能交易不等于能持续生存

以五类交易需求为背景：ProfitEffect、NewsReactor、Noise、Latecomer、Grid v2；加入 Value 的基础估值反应和 Coral 的库存报价。NewsV2、Hunter、Shark、Tracker 及命名强策略改为 Value/Coral 槽位，保留组顺序、人数区间、总现金和逐股总量。命名大资金槽位仍保留原大额资产，但均仅普通消息。匿名角色变动会改变 Value/Coral 资本池的组内分配，因此这不是仅移除一个强 bot 的孤立因果实验。

开发 91101–91106，两次重复、四种费用共 48 局，四种方案均未过线。正常状态的盘口、成交、数量深度及消息方向响应可满足基础门槛，主要失败在群体持续性、坏账、困境卖盘或烧股。没有按总市场收益选一个“健康赢家”。

## 有限风险约束的追加研究

根据开发账目另行登记 [补充协议](ecology-v22-repair-protocol.md)，只检验两个现有参数：Noise 单次最大订单设为 4 股；Coral 目标杠杆上限设为 1。没有改变观察和决策间隔、随机出手概率、股息或信息模型。使用零闲置费隔离风险约束，并额外保留原收费 legacy 保护困境卖盘，不把较差对照当作新的健康标准。

该研究的开发、独立验证和有条件强者回填各使用新的种子段；结果在对应冻结 JSON 中记录，不覆盖上述失败。参数组合的效果必须与单项分别比较，改善不能直接等同于证明单笔交易的盈利来源。

91401–91406，各两次，四种风险方案加原收费 legacy 共 60 局。下面四行均为零闲置费，因而两项调整没有混入收费差异：

| 开发方案 | Coral 净收益 | Coral 融资利息 / 初始权益 | Noise 毁损 90% 比例 | Grid 毛亏损份额 | 未通过项 |
|---|---:|---:|---:|---:|---|

| noise：仅单笔最多 4 股 | −39.67% | 39.05% | 2.98% | 28.83% | 骨干持续性 |
| coral：仅目标杠杆 1 | +20.04% | 0.06% | 23.07% | 31.26% | 坏账、Grid 亏损份额 |
| both：两项同时使用 | +16.16% | 0.06% | 1.39% | 36.47% | 坏账、Grid 亏损份额 |

## Grid 的问题不能只用亏损份额描述

both 相对 control 的 Grid 平均亏损略少，份额却提高，因为 Coral、Noise 少亏了。不能为了让 Grid 份额回到 30% 以下，故意恢复其他群体的损失。这里仍严格记录预设验收失败，但这个比率只是损失分布的保护线，不是完整的市场健康定义。

追加离线合同核对：在零闲置费的相同世界中，假设 Grid 保留全部初始股票、不提交交易，只领取普通股息和原固定组合、最后按合同兑现。逐 tick 与终局按引擎单位和舍入计算，所算账户全程现金非负，无须融资，没有交易费。这个静态账户的兑现额不依赖其他账户的价格路径；它不是重新模拟其余市场，也不能把差额全部说成对手利润。

| 世界批次 | Grid 实际交易净收益 | 初始组合静态兑现净收益 |
|---|---:|---:|
| 首批基础开发，none | −74.87% | +32.39% |
| 风险调整开发，both | −74.64% | +43.15% |
| 风险调整独立组，both | −74.53% | +30.31% |

最后十个世界中，Grid 实际表现全部低于静态兑现；静态组合九个世界盈利、一个亏损。**因此这批 Grid 的严重损失不能简单解释为“新增分红风险使初始股票都变成垃圾”。** 交易改变了它持有什么、何时领取现金流、支付多少交易费及最后剩下什么；下一步需要拆开买卖价差、卖出后错失的分红、库存再平衡和报价更新，不能凭这张表认定某一项已经是主因。静态兑现用到了赛后已实现世界，只作评价，不是供 bot 交易的未来估值。见 [静态现金流分析](ecology-v22-passive-analysis.json)。

修复候选中五类群体合计承担约 75.18% 毛亏损，ProfitEffect 约 28.67%、Grid 30.48%；Noise 平均转为小幅盈利，信息弱者在这批基础世界平均盈利较高。这说明“支付者”是行为分类，不能预设每组在每种阵容必亏。这里没有依据这种结果加强其错误决策去凑支付比例。

## 后续方向由本轮证据限定

目前最有依据的是继续研究基础参与者的风险与交易行为，而非追加更复杂的经营设定或为了 Swift 盈利改变世界。优先做 Grid 的交易/持仓归因，并检验 Value 对借款和负组合现金流的约束；费用以独立候选保留，不立即切换正式市场。消息窗口、强平和联动在本轮未做因果消融，不能声称已经验证它们都合理。

本轮也没有证明零闲置费对所有生态最优：它减少了资产烧毁、保留了本批活跃与信息响应，却不自动修复交易劣势，数量深度还有明确取舍。继续开发须使用新的世界，不能拿这次只差 0.48 个百分点的独立结果反复调参直到过线。

## 实现与复核

生产 Rust 和所有旧 bot 源码保持 04eb6d4 状态；新开发是可复用的离线指标、自动生成且逐字段校验的研究场景、冻结运行器及结果汇总。开始时完整 workspace 214 项测试通过，release 构建确认；离线指标、配置与静态合同另有 11 项合成/回归检查通过。

基础场景生成器首次静态检查发现漏掉位于原文件末尾的资本再分配表，在任何基础比赛开始前已修复，并加入全配置等价断言；费用场景直接复制完整原阵容，未受影响。另补充期后生效消息的排除条件，复查此前 136 局实际使用样本中此类事件为零，旧指标与结论不变。两次修正前后的源码、协议与哈希分阶段保留。

`tools/research_ecology_v22.py` 提供 prepare/fees/foundation/holdout/competition；`tools/research_foundation_repair.py` 提供 prepare/dev/holdout/competition。比赛阶段通过 `python tools/arena_gate.py --cwd . -- python tools/… 阶段` 串行运行。已存在输出目录时拒绝覆盖；旧冻结批次应使用对应提交或 `runs/` 下保存的源码/二进制，不用更新后的工作区伪称完全相同的冻结版本。
