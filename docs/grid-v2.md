# Grid v2：现金与库存受限的简单网格

为五类支付群体实验独立实现。没有阅读旧 Grid 代码，旧 `grid` 注册名和历史场景保留。新注册名 `grid_v2`，统计归入网格家族。

每只股票维护过去可见成交价格的指数均值作为网格中心，在中心上下固定比例报价。持仓超过个人中性比例时略微降低中心，持仓不足时略微提高中心，偏移最多 ±2%。报价不主动跨过当前看到的对手价。它仍然是低买高卖的逆势策略，不判断真实价值或未来价格。

每账户独立抽样：网格距离 0.3%–0.7%，中心记忆 30–120 ticks，总股票预算 65%–80%，单股预算 12%–18%，每笔规模 1.5%–3% 权益，报价寿命 5–12 ticks。场景显式参数可覆盖相应抽样。第五轮增加挂单量并缩小间距，用于检验盘口深度；现金和库存上限未放宽。

每 tick 都观察和维护报价。新订单共同使用实际可用现金、购买力和总库存预算；预留买单也计入占用。卖出受可卖数量限制，不借款、不做空、不预支卖出所得。每股最多一对报价，观察到旧报价过期、买价高于更新后的买入边界、卖价低于更新后的卖出边界或库存超限时先撤单，下一次观察才重新使用预算。卖出数量按限价和标记价的较大者限制。

相对旧网格，预期行为改变是：单边下跌时停止无限加仓，网格中心随观察价格移动；库存过重时更愿意卖出，库存不足时提高买入意愿。它仍然可能被更有信息的参与者成交，也可能在长期单边行情亏损；没有保本、固定盈利或资本补贴。

运行前静态审查：仅 `Start`/`Observation`，不读取新闻、股息、终值、社会信息、世界种子反推或外部文件。随机种子仅用于个人参数。新增测试覆盖双边报价、避免主动跨价、现金与库存上限、跨股票总预算、报价保留/刷新和信息隔离。引擎撮合、费用、消息及守恒规则不变。
