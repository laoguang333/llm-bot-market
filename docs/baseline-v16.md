# v16：Lattice 加入普通背景账户

默认 `scenarios/baseline.toml` 与 `scenarios/baseline-v16.toml` 完全相同。相对 [v15](baseline-v15.md)，只在阵容末尾追加一个 `lattice-incumbent`：现金 20,000 元、每股 20 股、消息倍率 1、无额外研究，使用 Lattice 默认参数。合计 103–227 个账户、17 种策略。

旧账户的资金、参数和权限均保留；成长起点仍为全局约 1/3，撮合、费用、强平、消息、终值规则均未修改。Lattice 每 5 ticks 决策，新增账户带来相应资金、股份和交易竞争，因此成交价格、其他账户收益及市场质量可能变化。没有通过降低原有 bot 的决策频率改善性能。

[Lattice 报告](lattice.md)记录独立实现、审查、失败实验、消融及 v15 挑战成绩。源码保持挑战时的冻结版本，不读取种子、隐藏世界或旧 bot 实现。加入基准后，`challenge scenarios/baseline.toml --bot lattice` 会额外加入第二个 Lattice，历史 v15 成绩不代表这个新挑战已经通过。原挑战复现脚本已绑定归档 `baseline-v15.toml`。

## 加入前后回归

使用 release 构建，线程数 4，种子 7、11、19，每个版本每种子运行一次，共 6 局。Windows 机器为 20 逻辑核心，所有运行共用 10 核 affinity 预算；各局串行执行，每对交替版本顺序，没有并行跑其他 CPU 基准。完整命令、配置和二进制哈希、质量检查、账户统计见 [逐局结果](baseline-v16-results.json)。

| 种子 | v15 → v16 账户数 | v15 模拟墙钟 / 秒 | v16 模拟墙钟 / 秒 | v15 → v16 质量全项通过 |
|---|---:|---:|---:|---|
| 7 | 162 → 163 | 4.348 | 4.086 | 是 → 是 |
| 11 | 169 → 170 | 5.206 | 4.984 | 否 → 否 |
| 19 | 165 → 166 | 4.795 | 4.322 | 是 → 否 |

这里记录模拟器报告的墙钟，包含启动与写出文件的 CLI 总墙钟另存于结果文件。每臂只有一次运行，多线程成交路径也有波动，不能据此宣称加入策略使引擎提速。

v15 的 seed 11 未通过 `max_gap_ticks` 和 `two_sided_share`；v16 的 seed 11 未通过 `two_sided_share`，seed 19 未通过这两项。质量全项通过分别为 2/3 和 1/3，没有放宽阈值或删去失败世界。该小样本用于配置和运行回归，不足以证明市场质量的长期变化，也不是新版本挑战认证。

| v16 种子 | Lattice 排名百分位 | 最终权益 / 初始权益 | 最大实际杠杆 |
|---|---:|---:|---:|
| 7 | 90.74 | 1.46 | 2.65 |
| 11 | 92.90 | 2.07 | 3.18 |
| 19 | 96.97 | 3.09 | 2.64 |

三局 Lattice 均零拒单、零强平、零额外研究消息。实际杠杆可能高于 2.5 倍目标敞口，原因包括成本区间、行情变化和成交偏差，目标值不是硬性账户上限。

## 核对项目

- 配置解析核对：v16 仅追加一个普通 Lattice；默认场景与 v16 字节一致，v15 原配置保留。
- 三对世界的原账户名单、初始资金、股份、策略和权限一致；新闻文件哈希、最终股息和终值支付表一致。
- 六局共 120 次守恒审计全部完成；所有账户零 bot 错误、零禁用、零跳过。
- 升级默认场景后的 workspace 测试 175 项全部通过，包含新增 Lattice 的 6 项测试。局部格式及 Clippy 检查通过；上游已有的全仓库格式和 Clippy 问题见 [Lattice 测试记录](lattice.md#审查与测试)。

```sh
python tools/build_release.py
python tools/arena_gate.py --cwd . -- python tools/validate_v16.py
```

验证脚本使用独立的 `runs/v16-validation` 目录，目录已存在时退出，防止覆盖原始结果。单局默认场景可运行：

```sh
target/release/llm-market.exe run scenarios/baseline.toml --out runs/v16-example --seed 7 --threads 4
```
