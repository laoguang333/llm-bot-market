# Lattice 普通账户挑战协议

开始于 2026-10-21，基于拉取后的主线 `ea8c9f4`。

- 默认 v15，10000 ticks；追加一个普通 `lattice` 挑战者，现金 2,000,000 分、每股 20 股、新闻倍率 1、无远期研究。保持引擎、背景阵容、手续费和验收门槛。
- 不阅读旧 bot 实现或共用策略工具；仅查看 bot 注册接口、公共 API、市场规则、场景和文档。所有新策略逻辑在独立模块中实现。
- 开发集 1–20，可用于失败诊断和有限参数比较；21–40 用于开发验证。这些都是项目已经使用过的种子。
- 冻结最终源码和 release 二进制后，跑传统可比集 1001–1020，以及预先指定的新验收集 **73001–73020**。传统集合不宣称为项目未见样本；新集合不用于选参。每组每种子运行一次，不按成绩挑选重跑。
- 门槛沿用 CLI：平均百分位至少 90，且至少 80% 的世界进入前 25%。同时报告资金回报、最低百分位、强平、拒单、程序错误和市场质量，不将排名验收等同于市场质量全部通过。
- Windows 20 逻辑核，所有构建和运行以 CPU affinity 共享最多 10 核。比赛固定 4 工作线程，由 `arena_gate.py` 串行调度；报告场景、种子、线程、重复次数、墙钟和哈希。
- 新 bot 运行前审查输入边界、成熟训练标签、订单预算和期末新闻截止；不使用 `Start.seed`、账号身份、文件、网络或隐藏世界。既有参赛代码沿用仓库已审查状态。
- 保存失败实验。消融在开发集执行，用于区分在线学习、新闻特征和费用管理的贡献。

初始假设是在线学习可适应当前对手产生的收益规律，而不把既有 bot 的固定参数或新闻曲线复制为新策略。仅使用价格、行业相对收益和 carry 的首版在 1–5 上失败；后续实验必须保留这一事实。
