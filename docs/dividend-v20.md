# v20 分红风险实验

本轮实现普通分红长期衰退、停息与不确定恢复，不增加经营指标，也不对股东收取负普通分红。候选场景是 `scenarios/dividend-v20.toml`；五类支付者交互场景是 `scenarios/dividend-v20-balanced.toml`。历史默认和策略实现保持不变。完整实验规则见[冻结协议](dividend-v20-protocol.md)。

## 实现

`world.dividend_risk` 缺省关闭。开启后，普通三层消息使用以当前分红为基数的乘法冲击；扣除对数方差的一半，使取整前普通冲击的条件期望保持当前水平。去掉旧模型 `max(当前分红, 初始分红/2, 1)` 的冲击幅度下限，零点不再靠负数截断制造反弹。整数率仍按原单位取整，因此极低正分红存在量化误差，不声称取整后严格无偏。

独立的逐股保留率路径作用于整个普通加成长分红。潜在状态只用于生成分红，不以公司类别或经营变量暴露给 bot。状态变化由世界种子预先生成，与持仓、价格、bot 身份及盈亏无关：

- 正常派息可以转为受损或停息；受损可以长期持续、改善或进一步停息。
- 停息只能通过显式随机恢复转为受损派息。正常市场利好、行业利好和成长更新都不能绕过零保留率。
- 恢复以受损前水平为参照，但恢复区间低于那个水平；反复受损可以永久降低中枢。原成长与普通消息仍会改变最终分红，所以恢复也不等于固定的初始分红倍数。
- 复核间隔与调整跨度按整局长度缩放；每次变动分四次释放。四次更新是可学习的公开统计规律，后续是否改善仍未知。

分红保留率更新和原消息按披露时间合并，对每条消息重新计算实际 delta，再生成完整真实分红路径。原来的真实变化区间、最终精确公开、生效延迟和研究提前量继续生效。公开 `Rules.dividend_risk` 只有过程分布参数，不含实现路径、状态或公司标签。

## 终局和组合的边界

保持最后生效普通分红乘隐藏期限的终局合同；普通分红为零时普通终值也为零，没有把初始分红或某个恢复目标补回去。尚未生效的新闻不提前进入终值。没有模拟完整破产、退市或终局后的无限未来。

原组合收益是独立的固定合同，停息股票仍可能因配对产生正或负组合现金流与终值。保留它们是为了单独识别分红过程的影响。因此这里的“停息”不等于彻底无价值，不能将价格高于零直接判为 bot 出错。费用、利息、仓位限制、撮合、个人时钟和决策频率均不改变。

## 验证与复现

新增七项回归测试覆盖停息、恢复、消息真实性与权限隔离，并使用一个只持有、不交易的测试账户逐 tick 对账，核对普通分红、组合现金流、终局、系统现金及股份。工作区全部测试通过；撮合优先级和消息投递旧测试继续通过。Clippy all-targets 对既有 `social.rs` 的 `items_after_test_module` 警告使用单项豁免，其余警告视为错误。

所有生产 bot 均保持已审查的 `694183c` 实现。三个测试数据构造器仅补 `dividend_risk: None`；未给 Tide 或其他策略加入新逻辑。release 构建与实验使用 Windows 10 核总亲和性预算，每局 4 个市场工作线程，场景串行运行。使用 `tools/validate_dividend_risk.py` 记录代码、配置、二进制哈希及完整命令，入口见冻结协议。

**不能声称已经消除了 Tide 的高收益。** 开发组 Tide 仍 20/20 盈利，独立组也 20/20 盈利；开发期平均百分位从 98.91 升到 99.47，独立期为 98.93 → 98.87。一些其他强 bot 受损远比 Tide 严重，尤其 Osprey、Kestrel 和 Coral。

独立组 Tide 普通股息收入由初始权益的 4.868 倍降到 2.754 倍，但组合收入由 0.123 倍升至 0.766 倍；交易/库存/终值残差从 2.993 倍升至 5.123 倍。残差包含终局估值及交易库存变动，不能称为纯交易利润或直接归因于某个支付群体。组合奖励依旧支付是明确的合同事实，但没有做组合开关消融，不能把全部额外收益归因于它。

与 v19 balanced 叠加的 6 对运行里，Tide 平均净收益从 +664.05% 升到 +1403.74%。这是仅 3 个世界的交互检查，不能当作新的泛化排名；它足以否定“加入坏公司必然让 Tide 更差”的判断。

## 流动性诊断与下一步

补充诊断按已经生效的消息重建每个股票/时刻分红，再分类统计所有盘口样本。该检查是事后诊断，没有替换事前验收。独立组分红仍高于初始 25% 的股票时段，双边覆盖为 v18 的 95.08%、v20 的 96.00%；低正分红时段为 56.75% → 52.17%；零分红时段为 24.66% → 25.79%。总体覆盖下降主要伴随低分红和停息时段占比提高，不能描述成所有股票的盘口都被破坏。不同状态和世界的样本构成不同，这些条件统计不是因果消融。

原质量指标用当前普通股息延伸作为价格参考，未计入持仓配对的组合合同；停息时这个参考接近零，容易放大估值偏离判定。与此同时，低分红资产确实存在长时间无买盘或无卖盘，不能仅凭估值指标局限忽略实际成交中断。金额深度还受股价下降影响。

下一步应分别验证：固定组合现金流在停息时是否仍应存续；低分红和停息资产的交易/退出规则；不同分红状态下的流动性标准。需要事前定义新的检验和独立样本，而不是直接降低风险参数、改变这轮门槛或修改 Tide 来凑排名。本轮保留可运行的候选、全部原始结果和失败结论。
