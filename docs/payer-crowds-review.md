# 五类支付群体：新增策略运行前审查

2026-10-21。新增 `news_reactor`（信息弱者）、`latecomer`（迟到者），共用新写的 `crowd_execution`；第四轮新增独立实现 `grid_v2`，审查见 [Grid v2](grid-v2.md)。审查范围为新增文件、注册表及新行为测试；没有阅读旧 bot 实现。旧策略沿用已有审查，本轮不改旧实现。

- 只接收 `Start`、`Observation`。没有文件、网络、进程、系统时间、引擎内部或赛后数据访问。`Start.seed` 只用于 ChaCha8 抽取各账户参数，未反推世界。
- 信息弱者只使用本人收到的普通新闻区间中点、可见股息及成交价格。忽略远期研究、终值提示、社会盈亏和成交方向。同一事件的后续披露替换旧估计，不重复累加，不刷新首次注意时间。第三轮新增价格信念：仅在新事件到达时记录可见成交价，新闻印象使个人可接受价格在该锚的 −35% 至 +60% 范围内变化；后续阶段不重设锚。没有真实未来股息或隐藏价值输入。新增测试核对价格误判确实进入委托限价，以及重复披露不能随现价重设同一事件的锚。
- 迟到者只使用已见成交价形成价格偏离信号，记录当时的价格和目标股数。意图到期前不发单；原价格限制不会随行情移动；执行窗口结束或反向证据出现则取消。延迟属于策略内部行为，不降低调度决策频率，不改消息投递。
- 两者在可接受价格内用 IOC，否则可在原意图价格边界内挂限价单。每股最多保留一笔；观察到 20 ticks 旧报价、目标方向或数量改变、价格超出边界、意图失效时撤单，下一次观察才使用释放的预算。不借款、不做空，不预支卖出收益。买单共同消耗一次调用内的现金与购买力预算；卖单受 `sellable` 限制。部分成交后使用实际持股继续计算差额。
- 参数有有限值和区间处理，记忆按实际 tick 间隔衰减；新闻状态按年龄清理。零股、无盘口、现金不足或非正权益时不会通过市价单强迫成交。第四轮修正低卖价的数量换算，以当前可见价格限制单笔股数，防止低限价意外扩大卖出规模。
- 新测试覆盖消息方向与修订、重复披露、注意年龄、买卖双向迟到、旧价限制与过期、反向证据撤销、部分成交、跨单现金预算、输入隔离和非正权益。第二轮补充无对手价时挂单、避免重复挂单、意图反转撤单、陈旧报价撤单，以及真实 Start 的逐账户/逐资产核对。

第五轮增量审查：信息弱者先过滤 `forecast || !public`，未公开消息不写入注意状态或价格锚，公开后正常建立首次印象；新增测试确认早期私有利好无订单、公开后才响应。网格只调整有限的默认间距和单笔规模，保留原现金、库存、报价生命周期约束。资本变化只通过既有守恒分配机制完成。

运行前静态审查结论：允许执行测试与模拟。守恒、消息和撮合继续由既有引擎检查与逐局审计验证；本轮不修改引擎。
